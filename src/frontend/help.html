ショートカット一覧

テキスト編集

行の折り返し切り替え
Alt + Z
行の上下移動
Alt + [↑] / [↓]
行の上下複製
Alt + Shift + [↑] / [↓]
行の削除
Alt + Shift + K
現在日時の挿入
F5
検索
Ctrl + F
置換
Ctrl + H
インデント挿入
Tab
インデント削除
Shift + Tab

ファイル・タブ操作

手動保存
Ctrl + S
新規タブ追加
Ctrl + T
タブを閉じる
Ctrl + W
エクスプローラーを開く
Ctrl + E
次のタブへ
Ctrl + Tab
前のタブへ
Ctrl + Shift + Tab

表示・ズーム

ズームイン (拡大)
Ctrl + [+] / [;] / マウスホイール上
ズームアウト (縮小)
Ctrl + [-] / [=] / マウスホイール下
ズーム・行間のリセット
Ctrl + 0
行間を広げる
Ctrl + Shift + [+] / [;] / マウスホイール上
行間を狭める
Ctrl + Shift + [-] / [=] / マウスホイール下

設定画面の操作

設定画面の開閉
Ctrl + ,
設定項目の移動 (次へ)
Tab
設定項目の移動 (前へ)
Shift + Tab
設定値の選択・変更
[↑] / [↓]
フォルダ選択ダイアログを開く
Space / Enter
設定を閉じてエディタに戻る
Esc

その他

ヘルプ画面を開く
F1
ヘルプを閉じる
Esc
アプリを終了
Ctrl + Q
