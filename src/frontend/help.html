ショートカット一覧

表示

行の折り返し切り替え
Alt + Z
行番号の表示切り替え
Alt + L
ルーラーの表示切り替え
Alt + R
インデントガイドの表示切り替え
Alt + I
不可視文字の表示切り替え
Alt + W

テキスト編集

行の上下移動
Alt + [↑] / [↓]
行の上下複製
Alt + Shift + [↑] / [↓]
行の削除
Alt + Shift + K
現在日時の挿入
F5
インデント挿入
Tab
インデント削除
Shift + Tab

検索・置換・移動

検索パネルを開く
Ctrl + F
検索・置換パネルを開く
Ctrl + H
次のマッチへ移動
Enter / ▼
前のマッチへ移動
Shift + Enter / ▲
大文字/小文字区別の切り替え
Alt + C
すべて置換
Alt + A
指定行へのジャンプ
Ctrl + G
※ -値: 行末からの行数へジャンプ、:指定: 指定列へカーソル移動
検索・置換・移動パネルを閉じる
Esc

フォントサイズ・行間

フォントを大きく (拡大)
Ctrl + [+] / [;] / マウスホイール上
フォントを小さく (縮小)
Ctrl + [-] / [=] / マウスホイール下
行間を広げる
Ctrl + Shift + [+] / [;] / マウスホイール上
行間を狭める
Ctrl + Shift + [-] / [=] / マウスホイール下
フォントサイズ・行間のリセット
Ctrl + 0

ファイル・タブ操作

ファイルを開く
Ctrl + O
手動保存
Ctrl + S
新規タブ追加
Ctrl + T
タブを閉じる
Ctrl + W
エクスプローラーを開く
Ctrl + E
次のタブへ
Ctrl + Tab
前のタブへ
Ctrl + Shift + Tab

設定画面の操作

設定画面の開閉
Ctrl + ,
設定項目の移動 (次へ)
Tab
設定項目の移動 (前へ)
Shift + Tab
設定値の選択・変更
[↑] / [↓]
フォルダ選択ダイアログを開く
Space / Enter
設定を閉じてエディタに戻る
Esc

その他

ヘルプ画面を開く
F1
ヘルプを閉じる
Esc
アプリを終了
Ctrl + Q
