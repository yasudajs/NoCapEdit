# NoCapEdit (nce)

> [!IMPORTANT]
> **NoCapEdit — 書くことを邪魔しないメモエディタ**
> 
> 起動直後からすぐに書き始められ、書いたものがすぐに保存されます。<br>
> 保存することを意識せず、思いついたことを、すぐに書き留められます。<br>
> あなたの **書くことを邪魔しない** 、シンプルで洗練された **メモエディタ** です。

一般的なテキストエディタで発生する「保存時にファイル名や保存場所を指定する」という手間をなくし、書くことに集中できるようになります。

起動時やタブ切り替え時、設定変更後もカーソル位置や選択状態、フォーカスが常に復元・維持されます。

ストレスフリーでシームレスなエディタ環境を、ぜひ体感してください。

用途やユーザー環境に合わせて以下から選択してください。

- **[ポータブル版（ZIP形式 / インストール不要）](https://github.com/yasudajs/NoCapEdit/releases/download/v2.13.0/NoCapEdit_v2.13.0_x64_portable.zip)**
  - ダウンロードしたフォルダを解凍するだけで、すぐに使い始められます。USBメモリなどに入れて持ち運ぶことも可能です。
- **[標準インストーラー（EXE形式 / 推奨）](https://github.com/yasudajs/NoCapEdit/releases/download/v2.13.0/NoCapEdit_2.13.0_x64-setup.exe)**
  - パソコンの個人用エリアにインストールするため、管理者権限（パスワード入力等）なしで簡単に導入できます。迷ったらこちらがおすすめです。
- **[システム全体用インストーラー（MSI形式）](https://github.com/yasudajs/NoCapEdit/releases/download/v2.13.0/NoCapEdit_2.13.0_x64_ja-JP.msi)**
  - 学校や職場などで、1台のパソコンを複数のユーザーで使う場合に適しています。（※インストールには管理者権限が必要です）

> [!IMPORTANT]
> **初回起動時・インストール時のセキュリティ通知について**
> 本アプリは個人開発のため商用デジタル署名を行っておりません。そのため、初回起動時やインストール時にWindowsから以下のような通知・警告が表示される場合がありますが、安全にご利用いただけます。
> - **「セキュリティ スキャンが必要です」と表示された場合（ポータブル版の初回起動時など）**:
>   Microsoft Defender による初回安全スキャンの通知です。数秒〜10秒ほど待つか「閉じる」を押してそのまま起動をお待ちください（スキャン完了後は2回目以降表示されなくなります）。
> - **「WindowsによってPCが保護されました」と表示された場合**:
>   画面内の **「詳細情報」** をクリックし、表示された **「実行」** ボタンを押して進めてください。
> - **「このアプリがデバイスに変更を加えることを許可しますか？」と表示された場合**:
>   **「はい」** を選択して進めてください。

## 🚀 主な特徴

### 💾 保存モードとファイル生成

1. **2つの保存モード（自動保存 / 手動保存）**
   - **自動保存モード（デフォルト）**: 文字の入力が停止してから **3秒後** に自動保存を行います。
   - **手動保存モード**: 自動では保存を行わず、`Ctrl + S` による手動操作時のみ保存を行います。設定画面からいつでも切り替え可能です。
   - 保存状態の更新は画面左下（ステータスバー）のテキスト（「編集中...」「保存済み」）のみで静かに表示され、ポップアップや通知など作業の集中を妨げる表示は一切行われません。
   - 手動保存モードで編集中にタブを閉じたりウィンドウを閉じた場合、**確認のメッセージは出ず、編集中の内容は破棄されます**ので、ご注意ください。
   - ファイル編集中にモードを切り替えた場合、開いているファイルにもモード変更が適用されます。

2. **自動保存モード時のファイル管理**
   - **文字を入力し始めてからファイルを作る機能**: 新しいタブを開いた（またはアプリを起動した）だけでは、まだパソコン内にファイルは作られません。文字を入力して最初の保存が行われたタイミングで、その時の日時を名前としたファイル（例: `20260713_184500.nctx`）が初めて自動作成されます。これにより、何も書いていない空のファイルが勝手にフォルダに増えるのを防ぎます（すでに同じ名前のファイルがある場合は、自動的に `_1`, `_2` のような連番が名前の後ろに付きます）。
   - **空になったファイルを自動で整理する機能**: 文字を何も入力しなかったタブや、スペース・改行だけを入力したタブを閉じたときは、余計なファイルが残らないように自動で整理（削除）されます。これにより、後から「中身が空っぽの不要なファイル」を自分で削除する手間がなくなります。

### 🗂 複数タブとキーボードナビゲーション

- **タブ管理**: 複数のファイルを同時にタブで開き、切り替えて作業することができます。タブがあふれた場合は自動でスクロールします（タブ領域上でマウスホイールを上下に回転させることで左右に横スクロールも可能です）。
- **ショートカット移動**: `Ctrl + Tab` (右のタブへ移動) / `Ctrl + Shift + Tab` (左のタブへ移動) を使って、キーボードから手を離さずにファイルを素早く切り替えられます。タブを閉じる操作（`Ctrl + W`）や新規作成（`Ctrl + T`）にも対応しています。
- **状態の保持**: タブ切り替え時やアプリ再起動時でも、各タブの直前のカーソル位置やスクロール状態が自動的に復元されます。

### 🔒 データの安全性とデザイン・カスタマイズ

3. **ファイルの安全な保存（保存エラーやファイル破損の防止）**
   - **オンラインストレージへの対応**: OneDriveなどのオンラインストレージ（同期フォルダ）内でも、保存エラーやファイルの破損が起こりにくい安全な保存方式を採用しています。
   - **重ねて操作しても安心**: 文字の入力中にタブを切り替えたり、アプリを閉じたりする操作が重なっても、保存の処理が衝突してファイルが壊れないように設計されています。

4. **テーマの切り替え（ダーク / ライト / ソフトダーク）**
   - 3種類のデザインテーマ（ダーク、ライト、目に優しいソフトダーク）の切り替えに対応しています（タイトルバーの色も連動します）。
   - 設定はアプリを再起動した後もそのまま維持されます。

5. **フォント・表示のカスタマイズ**
   - 設定画面（右ドック）から標準のフォントサイズや行間を数値で設定・保存できます。
   - 作業中に一時的に調整したい場合は、`Ctrl` + `マウスホイール` （または `Ctrl` + `+` / `-`）でフォントの拡大縮小、`Ctrl` + `Shift` + `マウスホイール` で行間の拡大縮小が可能です。変更内容は `Ctrl + 0` でいつでも標準設定にリセットできます。
   - **等幅フォント**（文字の横幅がそろっていて、プログラムやメモが整然と読みやすくなるフォント）と、それ以外のフォントを分けて選ぶことができます（遅延読み込み対応）。

6. **名前をつけて保存機能 (`Ctrl + Shift + S`)**
   - Windows標準の「名前をつけて保存」ダイアログ（Common Item Dialog）を開き、任意のフォルダや別ドライブへの保存・別名保存が可能です。
   - `NoCapEdit Text (*.nctx)` のほか、`*.txt`、`*.csv`、`すべてのファイル (*.*)` の拡張子フィルターに対応し、保存形式を自由に選択できます。

7. **拡張子別ファイルアイコンと Windows 連携**
   - NoCapEditに関連付けられたファイル（全47拡張子対応）に対し、エクスプローラー一覧で一目でファイル種別が判別できる**拡張子別専用アイコン**を導入。
   - 書類下部の帯バナーに大文字テキスト（CSV, TXT, MD, JSON, PY 等）とカテゴリ別カラー（表計算は緑、テキストは灰、マークダウンは青、データは橙など）を表示し、一覧での高い視認性を実現しています。
   - インストーラー版では各種拡張子の「プログラムから開く」や既定のアプリ関連付けに完全対応しています。

### 📐 執筆・レイアウトを支える表示補助

8. **行番号の表示 (`Alt + L`)**
   - エディタ左端に行番号を表示できます。ショートカット `Alt + L` で作業中タブの表示/非表示を即座に切り替えられるほか、設定画面から常時表示に設定することも可能です。

9. **水平ルーラーと指定桁縦ガイド線 (`Alt + R`)**
   - 等幅フォントの文字幅に連動した目盛りバーをエディタ上部に表示します。
   - 現在のカーソル桁位置を赤いアンダーラインでリアルタイム表示します（全角文字やタブ文字にも正確に追従）。
   - ルーラー上をクリックすると、任意桁にマーカー（▼）とエディタ本文への縦破線ガイド（Dashed）を設置できます（1タブ最大10個、ドラッグ移動やクリック削除可能）。桁数を揃えた文書や原稿、レイアウト調整に最適です。

10. **インデントガイドの表示 (`Alt + I`)**
    - タブやスペースによる字下げ構造に合わせて薄い縦補助線を描画します。
    - 空行でも途切れず自然に繋がり、プログラムや階層箇条書きのインデント構造がひと目で把握できます。

11. **空白・タブ・改行記号の可視化 (`Alt + Shift + I`)**
    - 半角スペース（微小ドット）、全角スペース（四角記号）、タブ文字（右矢印）、改行マーク（下向き左折れ矢印）を控えめに可視化します。
    - 編集作業やIME入力を邪魔しない薄型デザインを採用し、ショートカット `Alt + Shift + I` で即座に切り替え可能です。

### ⌨️ 便利な編集・検索・ジャンプ機能

12. **指定行・指定文字位置へのジャンプ (`Ctrl + G`)**
    - エディタ右上にコンパクトなジャンプUIを展開し、指定した行へスムーズに移動できます。
    - `-1` で最終行へ移動する「行末からの逆算指定」や、`15:10` のような「行:桁指定」にも対応しています。

13. **検索・置換 (`Ctrl + F` / `Ctrl + H`)**
    - コンパクトな検索・置換バーを展開し、すばやくテキストの検索や一括置換が行えます。

14. **タブ幅・インデント設定**
    - Tabキー押下時の挙動を「タブ文字 (4文字幅)」「タブ文字 (2文字幅)」「スペース (4文字)」「スペース (2文字)」から選択できます。

15. **豊富なテキスト編集ショートカット**
    - **行の折り返し**: `Alt + Z` で作業中のタブのテキスト折り返し（ON/OFF）を即座に切り替えられます。
    - **行操作**: `Alt + ↑ / ↓` で行の上下移動、`Alt + Shift + K` で行の削除など、便利な編集ショートカットを多数搭載しています（元に戻す `Ctrl + Z` にも完全連動）。
    - アプリ使用中に `F1` キーを押すことで、いつでもヘルプ画面（ショートカット一覧）を開いて操作方法を確認できます。

### ⚙️ バージョンと設定の管理

16. **バージョン表示および自動アップデート通知**
    - アプリケーションのタイトルバーに現在のバージョン番号が `NoCapEdit [ Ver a.b.c ]` の形式で表示され、現在のバージョンをひと目で確認できます。
    - 起動時に新しいバージョンがリリースされているかをバックグラウンドで自動チェックし、最新版がある場合はタイトルバーおよび設定画面内にアップデート通知（リリースノートへのリンク付き）を表示します。

17. **データの保存場所**
    - **作成したメモの保存先**: 「ドキュメント」フォルダ内の `nce` というフォルダに自動で保存されます。
    - 初回起動時や、設定された保存先フォルダが見つからない場合は、起動時に「保存先フォルダを選ぶ画面」が表示されます。
