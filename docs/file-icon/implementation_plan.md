# 詳細表示用ファイルアイコン（案A: WPSスタイル）実装計画書

## 概要
エクスプローラーの「詳細」「一覧」「小アイコン」表示（16px〜32px相当）において、ファイルアイコンの視認性を向上させるため、解像度ごとに最適化したデザイン（案A: WPSスタイル）をマルチ解像度 ICO ファイル（`icons/document.ico`）に組み込みます。

---

## 現状の課題と改善方針

### 現状の課題
- 現在の `icons/document.ico` は、512x512px の単一デザイン（角折れ用紙＋左上280pxロゴ）を全解像度（16px〜256px）に自動縮小して生成されています。
- エクスプローラー詳細表示（16x16px相当）では、用紙の白地ばかりが目立ち、左上の赤丸ロゴが数ピクセルに縮小されてしまうため、何のファイルか判別しづらくなっていました。
- ユーザー様にご提示いただいた実機画面の `小学漢字.xlsx`（WPS Spreadsheets）では、用紙の左〜中央にかけて大きな緑のSマーク（幅の約75%）が配置されており、極小サイズでもひと目で判別できる構造になっていました。

### 改善方針
Windows の `.ico` ファイルの**「解像度ごとのデザイン切り替え（Adaptive / Mipmapped Icon）」**仕様を活用します。

1. **大サイズ（48px / 64px / 128px / 256px）**:
   - デスクトップ等で好評をいただいた**現在のデザイン（角折れ用紙＋左上280pxロゴ＋罫線）を完全維持**。
2. **小サイズ（16px / 24px / 32px）**:
   - ユーザー様に選定いただいた**【案A: WPSスタイル】**を適用。
   - 白い角折れ用紙の左〜中央にかけて、NoCapEdit の赤丸ロゴを大きくオーバーレイ（幅の約72%）。
   - 16px でも赤丸シンボルがしっかりと視認でき、かつ角折れ用紙の輪郭も確認できるデザイン。

## 実装手順（ユーザー承認後に実施）

1. **小サイズ特化デザインの精密生成スクリプト作成**:
   - 16x16, 24x24, 32x32 それぞれのピクセルグリッドに最適化した「案A: WPSスタイル」の画像を生成。
2. **マルチ解像度 ICO ファイル（`icons/document.ico`）の合成**:
   - 16x16, 24x24, 32x32: 案A（WPSスタイル）
   - 48x48, 64x64, 128x128, 256x256: 現行デザイン（用紙＋左上280pxロゴ）
   - 上記すべてを統合した高品位 `.ico` ファイルを出力。
3. **ビルドと動作確認**:
   - `cargo tauri build` を実行して NSIS インストーラーを生成。
   - エクスプローラーの「大アイコン/中アイコン（デスクトップ）」と「詳細/一覧表示」の両方で、意図通りデザインが切り替わって表示されることを確認。
4. **ドキュメント更新とコミット**:
   - `task.md`、`walkthrough.md`、`history.md` を更新し、Git にコミット＆プッシュ。
