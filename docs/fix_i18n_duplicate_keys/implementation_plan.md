# 多言語辞書（i18n）重複キー修正 実装計画書

## 1. 概要
- **対象機能**: 検索バー（Ctrl+F）・置換ウィンドウおよびヘルプ画面における多言語テキスト定義の正常化
- **背景と課題**:
  - 検索・置換ウィンドウの表示時、プレースホルダーやボタン名が「検索」「置換」等の日本語ではなく、`ui.find.placeholder` や `ui.find.replace` 等のキー文字列のまま露出していた。
  - 調査の結果、[`src/frontend/i18n.js`](file:///d:/antigravity/NoCapEdit/src/frontend/i18n.js) の多言語辞書 `DICT.ja.ui` において、`find` オブジェクトが末尾（282〜284行目）で重複定義されており、182〜194行目の完全な定義が上書きされていたことが判明した。
  - 同時に、ヘルプ画面のショートカット定義 `DICT.ja.help.shortcuts` 内で `toggleWordWrap` が重複定義（136行目・170行目）されていることも判明した。
- **目的**:
  - 重複したキー定義を削除・整理し、検索・置換UIおよびヘルプ画面で正常に日本語が表示されるように修正する。
  - 辞書の整合性自動チェック手順を確立し、今後の再発を防止する。

---

## 2. 変更対象ファイルと修正内容

### ① [`src/frontend/i18n.js`](file:///d:/antigravity/NoCapEdit/src/frontend/i18n.js)
1. **`ui.find` の重複定義の削除**:
   - 282〜284行目にある以下の重複ブロックを削除する。
     ```javascript
                 find: {
                     replacedCount: "{count} 件を置換しました"
                 }
     ```
   - ※ 182〜194行目に同一の `replacedCount` を含む完全な `find` 定義が存在するため、182〜194行目の内容がそのまま有効化される。
2. **`help.shortcuts.toggleWordWrap` の重複行の削除**:
   - 170行目にある重複した以下の行を削除する。
     ```javascript
                     toggleWordWrap: "行の折り返し切り替え",
     ```
   - ※ 136行目に同一の定義が存在するため、定義の欠落は発生しない。
