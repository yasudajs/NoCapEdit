# NoCapEdit v2.13.0 リリースノート下書き

## タイトル: NoCapEdit v2.13.0 - 正式版リリース & 拡張子別ファイルアイコン機能追加

---

NoCapEdit 正式版（v2系）として初となるアップデート **v2.13.0** をリリースしました！🎉

これまでのベータ版（v0.2系）における数多くの開発実績を経て、セマンティックバージョニング（SemVer）に基づく正式版へ移行しました。
本バージョンでは、エクスプローラー上でファイルの種類が一目で判別できる **「拡張子別専用ファイルアイコン（全47拡張子対応）」** の導入をはじめ、Windows標準ダイアログによる **「名前をつけて保存 (`Ctrl + Shift + S`)」**、**「不可視文字の表示 (`Alt + Shift + I`)」**、行番号とルーラーの完全整合など、日々のメモ執筆やテキスト編集を一段と快適にする機能が多数追加・改善されています。

---

### 🌟 主な新機能・改善点

#### 1. 🎨 拡張子別専用ファイルアイコンの導入（全47拡張子対応）
- NoCapEditに関連付け可能なすべての拡張子（全47種）に対し、Windowsエクスプローラー一覧で一目でファイル種別が判別できる専用マルチ解像度アイコン（ICO）を新設しました。
- **下部2段分バナースタイル＆中央配置デザイン**: 書類下部の下から2段目の罫線から底辺まで（高さ約117px）にカテゴリ別カラーの角丸帯バナーを配置し、大文字テキスト（CSV, TXT, MD, JSON, PY 等）を帯の中央に太字（Segoe UI Black）で配置。中アイコン（48px）や小アイコン（32px）表示でも優れた視認性を発揮します。
- **カテゴリ別カラーリング**:
  - 📊 **表計算・データ**: CSV, TSV（Excelグリーン系）
  - 📝 **テキスト・ログ**: TXT, TEXT, LOG（スレートグレー系）
  - 📘 **Markdown**: MD, MARKDOWN（スカイブルー系）
  - ⚙️ **データ・設定**: JSON, JSONL, XML, YAML, YML, INI, CONF, CFG, ENV（オレンジ／アンバー／ティール系）
  - 🔴 **NoCapEdit専用形式**: NCTX, NCMD（ブランドレッド／ワイン系）
  - 💻 **Web・プログラミング言語**: HTML, CSS, SCSS, JS, TS, JSX, TSX, PY, RS, GO, JAVA, C, H, CPP, HPP, CS, PHP, RB, LUA, SQL, SH, PS1（各言語公式系カラー）
  - 🗃️ **バックアップ・一時**: BAK, TMP, TEMP（ミュートグレー系）
- **NSISインストーラー連携**: インストーラー版において各拡張子専用のProgID（`NoCapEdit.csv` 等）を登録し、「プログラムから開く」候補（`OpenWithProgids`）や既定のアプリ設定にも完全対応しました（アンインストール時の自動クリーンアップにも対応）。

#### 2. 💾 Windows標準「名前をつけて保存」機能の追加 (`Ctrl + Shift + S`)
- ショートカットキー `Ctrl + Shift + S` により、Windows標準の「名前をつけて保存」ダイアログ（Common Item Dialog）を開けるようになりました。
- 任意のフォルダへの保存や新規フォルダ作成、別ドライブや外部ストレージへの自由な別名保存に対応しています。
- **ファイルの種類フィルター**: `NoCapEdit Text (*.nctx)`（デフォルト）、`Text Files (*.txt)`、`CSV Files (*.csv)`、`すべてのファイル (*.*)` をサポート。
- **安全なライフサイクル**: 元ファイルはそのまま保持したまま、作業中のタブの対象ファイル・表示名を新ファイルへ安全に切り替えます。
- **UIフリーズ＆カーソル非表示対策**: Win32 APIによりダイアログ表示時のUIフリーズを防止し、文字入力中のポインター非表示状態を強制解除してマウスカーソルを確実に可視化する恒久対策を実施しました。

#### 3. 🔍 空白・タブ・改行記号の可視化（不可視文字の表示機能 `Alt + Shift + I`）
- 半角スペース（中央極小丸ドット）、全角スペース（中央四角記号 `□`）、タブ文字（右矢印 `→`）、改行マーク（下向き左折れ矢印 `↵`）をエディタ上で可視化できるようになりました。
- 執筆やテキスト編集を邪魔しない控えめで薄いデザインを採用しており、ショートカットキー `Alt + Shift + I` で即座に表示／非表示を切り替えられます。

#### 4. 📐 行番号表示時の左余白最適化＆ルーラー位置の完全整合
- 行番号表示時（`Alt + L`）にエディタ本文左側に存在していた余白を最適化し、行番号境界線（ガター右端の縦線）の直後からテキストが綺麗に開始されるよう改善しました。
- 水平ルーラー（`Alt + R`）の0桁目目盛りおよび赤いカレットインジケーターが行番号境界線と一直線に揃うよう完全連動しました。

#### 5. 🏷️ 正式版（v2系）への移行
- セマンティックバージョニング（SemVer）に準拠した正式版（v2系）へ移行しました。
- タイトルバーにも現在のバージョン番号（`NoCapEdit [ Ver 2.13.0 ]`）が表示されます。

---

### 🛠️ その他の改善・不具合修正

- **長大行描画の例外解消**: 折り返しOFFでの長大行（約4,000文字超）や折り返しONでの超長大行（約20,000文字超）において、CodeMirror 6 の描画最適化（line gap）による不可視文字プラグインの描画例外を解消しました。
- **インデントガイドの重複登録防止**: インデントガイド Widget の二重追加を防止し、画面外の不要な探索をスキップしてパフォーマンスを向上させました。
