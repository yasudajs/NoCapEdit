# ルーラー カーソル位置インジケーター改善 ウォークスルー (Ver 0.2.33)

## 1. 概要
ルーラー上に表示されていたカーソル位置インジケーター（旧仕様：全高25pxの赤い縦棒）が目立ちすぎ、ルーラーの数字や目盛り、タブと被って主張が強かったため、**「ルーラー内側最下端、高さ1px、1文字幅（アンダーライン）」**へと洗練されたデザインに変更しました。

---

## 2. 変更内容の詳細

### 2.1 CSSスタイルの修正 (`src/frontend/style.css`)
- `.ruler-cursor`:
  - `height: 100%`（25px）から `height: 1px` に変更。
  - `bottom: 0` のまま維持し、ルーラー領域の内側最下端（グレー境界線 `border-bottom` の直上）にアンダーラインとして密着配置。
  - `width: 0` に変更（JS側で半角1文字幅を動的適用）。

### 2.2 JavaScriptインジケーター制御の修正 (`src/frontend/js/ui/ruler.js`)
- `updateRulerCursor()`:
  - `getCharWidth()` から現在のエディタ等幅フォントの半角1文字幅を取得。
  - `elements.rulerCursor.style.width = \`${charWidth}px\`` を追加。
  - エディタのキャレットX座標（`cursorX`）を始点として、これから入力される1文字分の枠幅に正確にアンダーラインを表示。
  - ウィンドウリサイズ、フォント変更、フォントサイズ変更（ズーム）時にも `syncRulerMetrics()` を経由して文字幅・位置が自動追従。

### 2.3 仕様書・ドキュメントの更新
- `docs/spec.md`:
  - ルーラーの表示仕様に「エディタ内のキャレット移動に追従し、ルーラー内側最下端に半角1文字幅・高さ1pxの赤いインジケーター（アンダーライン）を表示する。」を反映。
- `docs/DEVELOPMENT.md`:
  - ビルドコマンド例のバージョン表記を `0.2.33` に更新。

### 2.4 バージョン番号の更新 (0.2.33)
以下のバージョン管理5ファイルをセットで `0.2.32` から `0.2.33` に更新しました。
