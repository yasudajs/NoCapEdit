# 実装計画書: エディタ要素上での標準コンテキストメニュー許可修正

## 概要
リリースビルド（本番環境）において、画面全域での右クリック無効化ロジック（`e.preventDefault()`）により、テキストエディタ（`textarea`）や入力欄（`input`）の上でも右クリックコンテキストメニュー（コピー・切り取り・貼り付け等）が抑止されていた問題を修正します。

## ユーザー確認事項
- テキストエディタ（`textarea`）および入力項目（`input`）の上での右クリック時のみ、標準コンテキストメニューの表示を許可します。
- それ以外の画面領域（サイドバー、タイトルバー、ステータスバー、背景部分など）では、従来通り不要なブラウザ標準メニューの表示を抑止します。

## 変更内容

### フロントエンド (JavaScript)

#### [MODIFY] [main.js](file:///c:/work/NoCapEdit/src/dist/js/main.js)
- `contextmenu` イベントリスナー内のロジックを更新：
  - 右クリックされたターゲット要素 (`e.target`) のタグ名が `TEXTAREA` または `INPUT` の場合は `e.preventDefault()` の呼び出しをスキップし、標準コンテキストメニューを許可する。
