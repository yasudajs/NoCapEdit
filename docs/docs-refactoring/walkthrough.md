# ドキュメント整理・再編集 ウォークスルー (walkthrough.md)

Ver 0.2.23 に向けて、肥大化・重複・記述粒度のバラつきが生じていた製品仕様書（`docs/spec.md`）およびアーキテクチャ設計書（`docs/ARCHITECTURE.md`）の整理・再編集を実施しました。

---

## 1. 実施内容の概要

### 1.1 `docs/spec.md` の改善点
- **セクションの論理的再編**:
  - 80行以上に及んでいた旧「4.4 テキスト編集と保存仕様」を、以下の3つの論理的な章へ分割しました。
    - **4.4 テキスト編集機能**: 文字コード、行操作、タイムスタンプ挿入、検索・置換、IMEインライン入力、選択ハイライト
    - **4.5 ファイル保存と安全保護**: 保存モード（自動/手動）、自動保存トリガー、手動保存（`Ctrl+S`）、空ファイル自動クリーンアップ、安全保存（一時ファイル置換）、リカバリ
    - **4.6 ファイルオープンと読み込み安全ガード**: `Ctrl+O`、D&D、右クリックメニュー連携、初期空タブ置換、サイズ上限/バイナリガード、シンタックスハイライト
  - 以降の章番（4.7 画面表示、4.8 ファイル関連付け、4.9 ユーザー設定、4.10 自動アップデート、4.11 ショートカット・ヘルプ・メニュー制限）を整頓しました。
- **アーキテクチャ詳細の ARCHITECTURE.md への移管**:
  - 旧4.8節「設定値・定数の一元管理方針（ハイブリッドアプローチ）」を `spec.md` から削除し、`ARCHITECTURE.md` へ統合しました。
  - ファイル専用アイコンやレジストリ登録の微細な内部仕様（画像ピクセル数やレジストリ詳細）を整理し、仕様書では機能的な挙動のみを明記して設計詳細へ委託しました。
- **矛盾・古い記述の解消**:
  - 「5.1 将来の拡張候補」に残っていた実装済みの「既存ファイルを開く機能」を削除しました。
  - 冒頭リンクの別環境絶対パス（`c:/work/...`）を相対リンクへ修正しました。
  - ショートカット無効化における `F5`（現在日時挿入）の記述を明瞭化しました。
- **ショートカット記述の `SHORTCUTS.md` への参照一元化**:
  - 行操作、検索・置換、フォントサイズ・行間ズーム、折り返しトグル、無効化キー等について、個別のキー一覧表の重複記述を廃止し、[SHORTCUTS.md](SHORTCUTS.md) への参照に集約しました。これにより仕様書がさらにスリム化され、キーボード操作の二重管理を防止しました。
- **目次リンクの新設**:
  - 仕様書冒頭に見出しリンク目次を新設し、必要な仕様へ迅速にジャンプできるようにしました。

### 1.2 `docs/ARCHITECTURE.md` の改善点
- **内部設計の集約と充実**:
  - 「3.2 設定値・定数の一元管理方針（ハイブリッドアプローチ）」を新設し、Rust / CSS / JS の役割分担を明記しました。
  - 「3.6 単一ウィンドウ動作（シングルインスタンス）とプロセス間通信」を新設し、`tauri-plugin-single-instance` による名前付きパイプ通信と外部ファイル連携フローを記述しました。
  - 「3.7 ファイル専用アイコンおよび OS 関連付け設計（NSIS連携）」を新設し、アプリアイコンとドキュメントアイコンの二重構造、マルチサイズICOの設計意図、NSIS による ProgID や SupportedTypes のレジストリ登録構造を体系化しました。
- **目次の新設と構成の統一**:
  - バックエンド、フロントエンド、アセット・インストーラーのディレクトリ構成と設計方針をわかりやすく整理しました。
