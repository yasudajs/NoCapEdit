# 行の折り返し切り替え（Word Wrap）機能 実装計画書

## 概要
長い文章やログファイル、ソースコードなどを快適に閲覧・編集できるように、**「行の折り返し（Word Wrap）」** の切り替え機能を実装します。
ショートカット（`Alt + Z`）によるタブ単位の一時切り替えと、設定画面（右ドック）によるアプリ全体のデフォルト永続化の2段階で制御します。

---

## 仕様詳細

| 操作 | 対象 | 永続化 | 挙動 |
|---|---|---|---|
| **ショートカット (`Alt + Z`)** | **現在のアクティブタブ** | **一時的（非永続）** | 現在のタブの折り返し状態（ON/OFF）を即座に反転。<br>タブを切り替えた場合もそのタブの個別状態を保持。 |
| **設定画面（右ドック）** | **アプリ全体（全タブの初期値）** | **永続化 (`config.json`)** | 「有効（折り返す）」/「無効（折り返さない）」を選択。<br>変更時は全タブのデフォルトとして保存され即時反映。 |

### 表示スタイル仕様
- **折り返し有効（ON / デフォルト）**:
  - `textarea` の `wrap="soft"`（および `white-space: pre-wrap; word-break: break-all;`）
  - ウィンドウ右端で自然に次の行へ折り返す（横スクロールバーなし）。
- **折り返し無効（OFF）**:
  - `textarea` の `wrap="off"`（および `white-space: pre; overflow-x: auto;`）
  - 折り返さずに横に伸び、画面下部に横スクロールバーを表示。

## 変更内容の詳細

### 1. Rust バックエンド (`src-tauri/src/main.rs`)
- `AppSettings` 構造体に `word_wrap: Option<bool>` を追加。
- 設定読み込み時、未設定の場合は `true`（有効）をデフォルトとする。

### 2. フロントエンド状態管理 (`src/dist/js/state.js`)
- `appState.wordWrap`: 基本設定（デフォルト: `true`）を保持。
- `Tab` オブジェクトに `wordWrap?: boolean` を追加し、タブごとの一時状態を保持。

### 3. エディタモジュール (`src/dist/js/ui/editor.js`)
- `applyWordWrap(enable: boolean)`:
  - エディタ（`textarea`）の `wrap` 属性および CSS クラスを適用。
- `toggleWordWrap()`:
  - 現在のアクティブタブの `wordWrap` 状態をトグルし、`applyWordWrap()` で即座に画面へ反映。

### 4. タブ切り替え連動 (`src/dist/js/ui/tabs.js`)
- タブ切り替え時（`switchTab`）、切り替え先タブに `wordWrap` が設定されていればそれを適用、なければ `appState.wordWrap` を適用。

### 5. 設定ドックUI (`src/dist/index.html`, `settings.js`, `style.css`, `i18n.js`)
- `index.html`: 設定ドック内に「行の折り返し」セレクトボックスを追加。
- `settings.js`:
  - 変更時に `appState.wordWrap` を更新し、設定保存。
  - 現在のタブの折り返し状態も更新・適用。
  - フォーカス可能要素リストにセレクトボックスを追加（キーボードナビゲーション連動）。
- `i18n.js`: 設定項目名・選択肢・ヘルプ項目の多言語キーを定義。
- `style.css`: `wrap="off"` 時の横スクロール用スタイルを定義。

### 6. ショートカット (`src/dist/js/ui/shortcuts.js`, `src/dist/help.html`)
- `shortcuts.js`: `Alt + Z` 押下時に `toggleWordWrap()` を呼び出す。
- `help.html`: 「表示・ズーム」カテゴリに `Alt + Z: 行の折り返し切り替え` を追加。

### 7. 仕様書およびドキュメント更新（※作業開始時）
- バージョン番号を `0.1.82` から `0.1.83` に更新（4ファイル一括更新）：
  - `Cargo.toml`
  - `tauri.conf.json`
  - `nsis/installer.nsi`
  - `docs/DEVELOPMENT.md`
- ドキュメント更新：
  - `docs/spec.md`: 行の折り返し仕様を追記
  - `docs/SHORTCUTS.md`: `Alt + Z` を追記
  - `docs/USER_GUIDE.md`: 操作説明を更新
