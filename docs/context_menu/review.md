# コードレビュー: v0.2.13 〜 v0.2.18 の機能追加

> レビュー日: 2026-09-10  
> 対象バージョン: Ver 0.2.13 → 0.2.18

---

## 全体評価

v0.2.13 から v0.2.18 にかけて、**ファイルオープン基盤 → 文字コード対応 → 安全ガード**と段階的に機能を積み上げており、設計の一貫性と品質が高い水準で維持されている。

---

## 発見事項

### 🟡 軽微な改善点（2件）

いずれも実動作上は問題なく、コーディング規約（i18n 準拠）上の軽微な不整合。次回の改修時にまとめて対応するレベル。

#### 1. ヘルプウィンドウタイトルのハードコード

- **ファイル**: `src/frontend/js/ui/shortcuts.js` L61 付近
- **内容**: F1キー押下時のヘルプウィンドウ生成で、タイトルが日本語リテラルでハードコードされている。
  ```javascript
  title: 'ショートカット一覧'  // ← ハードコード
  ```
- **改善案**: `i18n.js` に `help.title: "ショートカット一覧"` が既に定義済みのため、`t('help.title')` に差し替える。
- **影響度**: 低（現時点では日本語のみのため実動作に影響なし）

#### 2. 置換メッセージのフォールバック文字列に日本語リテラル

- **ファイル**: `src/frontend/js/ui/findReplace.js` L296
- **内容**: `t()` の戻り値が falsy な場合のフォールバックに日本語リテラルが含まれている。
  ```javascript
  const msg = (t('ui.find.replacedCount') || '{count} 件を置換しました').replace('{count}', totalCount);
  ```
- **改善案**: `t()` は辞書にキーが存在する限り必ず文字列を返すため、フォールバック文字列を除去するか、言語に依存しないプレースホルダー形式に変更する。
- **影響度**: 低（`t()` が正常に動作する限り到達しないコードパス）

## 特に優れている点（5件）

1. **Rust ↔ JS 間の i18n 疎結合設計**: Rust 側は表示テキストを一切持たず i18n キー（`fs.error.fileTooLarge` 等）のみを返却し、フロントエンドの `t()` 関数で解決。将来の多言語化にそのまま耐えうる設計。
2. **アトミック保存**: `NamedTempFile` を使った安全なファイル書き込みにより、書き込み途中のクラッシュでも元ファイルが破損しない。
3. **サイズチェックのタイミング**: `fs::metadata` によるサイズチェックをメモリ読み込み**前**に実施し、OOM（メモリ不足）を完全に回避。
4. **CodeMirror 6 の動的再構成**: `Compartment` パターンにより、タブ切替・設定変更・ファイル名変更時のハイライト/フォント/折り返しの差し替えがクリーンに実装されている。
5. **エラー時の安全設計**: バイナリ/巨大ファイルのエラー時にタブを作成せず、既存の作業状態を完全に保護。モーダル→既存画面復帰の流れが安全。
