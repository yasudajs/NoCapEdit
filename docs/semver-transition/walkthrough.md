# ウォークスルー: セマンティックバージョニング（v2.10.3）移行および運用ルール改定

## 1. 概要
NoCapEdit はエディタ基盤の近代化（CodeMirror 6 移行）以降、安定した機能追加と品質改善を重ねて成熟したソフトウェアとなりました。
これを受け、バージョン番号をベータ版（`v0.2.x`）から正式版（`v2.x.y`）へ移行し、セマンティックバージョニング（SemVer 2.0.0）に基づく明確なリリース体系へ昇格させました。

---

## 2. 実施した変更内容

### ① プロジェクト固有ルール (`.agents/AGENTS.md`) の改定
* **「5ステップごと」ルールの撤廃**:
  * ベータ期間中に目安としていた機械的な「5ステップごとのリリース（0.2.20, 0.2.25...）」ルールを削除しました。
* **セマンティックバージョニング運用の確立**:
  * バージョン番号の管理方針を SemVer（`v2.x.y`）に一本化。
  * **MINOR（中バージョン）**: 新機能や設定項目を追加した場合にインクリメント（例: `v2.10.3` → `v2.11.0`、PATCHは0にリセット）。
  * **PATCH（小バージョン）**: 不具合修正、表示崩れ修正、パフォーマンス改善、リファクタリング、微小なUX改善を行った場合にインクリメント（例: `v2.10.3` → `v2.10.4`）。
  * **本番リリース（GitHub Release）**: 新機能や不具合修正が完成・検証されたタイミングで都度作成する明快なサイクルへ統一。

### ② バージョン管理5ファイルの同期更新 (`2.10.3`)
プロジェクト規約で定められた以下の5ファイルをセットで `0.2.34` から `2.10.3` へ更新しました。

| ファイル | 更新箇所 | 更新後の値 |
|---|---|---|
| `Cargo.toml` | `version` | `"2.10.3"` |
| `package.json` | `"version"` | `"2.10.3"` |
| `tauri.conf.json` | `package.version` | `"2.10.3"` |
| `nsis/installer.nsi` | `VERSION` / `VERSIONWITHBUILD` | `"2.10.3"` / `"2.10.3.0"` |
| `docs/DEVELOPMENT.md` | ポータブル版ZIPビルドコマンド | `NoCapEdit_v2.10.3_x64_portable.zip` |

### ③ 製品仕様書 (`docs/spec.md`) の更新
* 対象バージョン表記を `Windows向け v2.x.y (現在バージョン: v2.10.3)`、最終更新日を `2026-10-04` に更新。
* 自動アップデートチェック機能の仕様記述を最新の実装（ドラフト・プレリリースを除外した最新正式リリースの全系統判定 `compareVersions`）に合わせて同期。

### ④ 改定履歴 (`docs/history.md`) の更新
* ドキュメント冒頭を「v2系 (正式版)」に改定。
* 最上部に **`Ver 2.10.3`** のエントリを追加し、正式版への移行背景、SemVer換算の経緯、および新リリース方針を記録。

## 4. 今後の開発・リリースフロー

次回以降の開発作業は以下のフローで進行します。

1. **修正・機能追加の計画**:
   * 内容に応じて次のバージョンを決定（新機能なら `v2.11.0`、不具合修正なら `v2.10.4`）。
2. **実装と検証**:
   * 実装完了後、ウォークスルーと変更履歴（`docs/history.md`）を作成。
3. **マージとリリース**:
   * `master` ブランチへの非Fast-forwardマージ（`--no-ff`）。
   * 必要に応じて GitHub Release を作成し、正式版として配布。
