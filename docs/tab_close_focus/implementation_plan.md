# タブを閉じた際のフォーカス移動の改善

タブを複数開いている状態でフォーカス中のタブを閉じた際、常に最も左側のタブへフォーカスが移動してしまう挙動を修正し、自然な形で隣のタブ（右隣、存在しなければ左隣）へフォーカスが移動するように改善します。

## Proposed Changes
### src/dist/js/ui/tabs.js
- `closeTab` 関数内において、アクティブなタブを閉じた際のフォーカス移動先を常に「一番左（`appState.tabs[0]`）」ではなく、「閉じたタブの隣」を選択するように修正します。
- 削除したタブのインデックスを元に、同インデックス（詰められた右隣のタブ）、あるいは配列外になれば末尾（左隣のタブ）を選択するよう `Math.min(idx, appState.tabs.length - 1)` を用いて実装します。

## Verification Plan
### Manual Verification
以下のケースを手動でテストし、挙動を確認します。
1. **真ん中のタブを閉じる**: 3つ以上のタブを開き、真ん中のタブを選択して閉じた際、元々「右隣」にあったタブにフォーカスが移動することを確認する。
2. **一番右のタブを閉じる**: 複数のタブを開き、一番右のタブを選択して閉じた際、元々「左隣」にあったタブにフォーカスが移動することを確認する。
3. **アクティブでないタブを閉じる**: 複数のタブを開き、アクティブではないタブを閉じた際、フォーカスが移動せず、元のタブがアクティブなままであることを確認する。
