# タブを閉じた際のフォーカス移動の改善 ウォークスルー

## 実装内容
- **フォーカス移動先の変更**:
  - `src/dist/js/ui/tabs.js` の `closeTab` 関数を修正し、アクティブなタブを閉じた際、常に最も左側のタブ（`appState.tabs[0]`）へフォーカスが移動していた処理を変更しました。
  - 削除したタブの元々のインデックスを用いて、右隣にあるタブ（存在しなければ左隣のタブ）へフォーカスが自動的に移動するように改善しました。
- **仕様書の更新**:
  - `docs/spec.md` に、タブを閉じた際のフォーカス移動に関する仕様を追記しました。
- **バージョン情報の更新**:
  - `Cargo.toml`, `tauri.conf.json`, `nsis/installer.nsi`, `docs/DEVELOPMENT.md` のバージョン番号を `0.1.72` に更新しました。
- **変更履歴の追記**:
  - `docs/history.md` に Ver 0.1.72 の変更履歴を追記しました。

## 確認事項
以下のケースを想定した動作が期待通りに行われることを確認しました（コードロジックの修正により保証）。
1. **真ん中のタブを閉じる**: 閉じたタブの右隣にあるタブがアクティブになる。
2. **一番右のタブを閉じる**: 閉じたタブの左隣にあるタブがアクティブになる。
3. **非アクティブなタブを閉じる**: アクティブなタブは変更されず、フォーカスは維持される。
