# 設定画面のキーボード完全操作（フォーカス制御とナビゲーション） 実装計画書

## 概要
`Ctrl + ,` で設定画面（設定ドック）を開いた後、マウスを使わずにキーボードのみで上から順に設定項目を確認・変更し、スムーズにエディタへ戻れるようにキーボードナビゲーション機能を実装します。

---

## キー操作フロー仕様

| 操作 | キー | 挙動 |
|---|---|---|
| **設定を開く** | **`Ctrl + ,`** | 設定ドックを開き、最上部の **[参照...] ボタンに自動フォーカス** |
| **項目間の移動** | **`Tab`**（次へ）<br>**`Shift + Tab`**（前へ） | 上から順に各設定コントロールへフォーカス移動（末尾まで到達したら先頭へループ） |
| **項目の変更** | **`↑` / `↓`（方向キー）** | フォーカス中のセレクトボックスの選択肢を切り替え |
| **ドロップダウン展開** | **`Enter`** または **`Space`** | ドロップダウン一覧を展開し、上下キーで選択・Enterで確定 |
| **フォルダ選択ダイアログ** | **`Enter`** または **`Space`** | [参照...] ボタンにフォーカス時、フォルダ選択ダイアログを起動 |
| **設定を閉じてエディタ復帰** | **`Esc`** または **`Ctrl + ,`** | 設定ドックを閉じ、**エディタの直前のカーソル位置へ即座にフォーカス復帰** |

---

## 変更内容の詳細

### 1. 設定モジュール (`src/dist/js/ui/settings.js`)
- `openSettingsDialog()` の改善:
  - 開いた直後に `elements.browseFolderBtn.focus()` を実行し、初期フォーカスをセット。
- フォーカストラップおよびキーナビゲーションの実装:
  - 設定ドック内のフォーカス可能要素リスト（参照ボタン、フォント、Tab挙動、保存モード、文字数カウント、テーマ）を管理。
  - ドック内での `Tab` / `Shift + Tab` 押下時に、最後の項目から先頭（または先頭から最後）へ適切にフォーカスをループさせる。
  - ドック内での `Esc` 押下時に確実に `closeSettingsDialog()` を呼び出す。

### 2. エディタモジュール (`src/dist/js/ui/editor.js`)
- `handleTabKey(e)` のガード処理:
  - 設定ドックが開いている状態では、エディタのインデント挿入処理を行わず、ブラウザ標準のフォーカス遷移を許可する。

### 3. スタイル調整 (`src/dist/style.css`)
- 設定ドック内の各コントロール（ボタン、セレクトボックス）の `:focus-visible` スタイルを強化し、現在どこにフォーカスがあるかが一目でわかるようにアクセント枠線・視認性を向上。

### 4. 仕様書およびドキュメント更新（※作業開始時）
- バージョン番号を `0.1.81` から `0.1.82` に更新（4ファイル一括更新）：
  - `Cargo.toml`
  - `tauri.conf.json`
  - `nsis/installer.nsi`
  - `docs/DEVELOPMENT.md`
- ドキュメント更新：
  - `docs/spec.md`: 設定画面のキーボードナビゲーション仕様を追記
  - `docs/SHORTCUTS.md`: 設定画面でのキーボード操作案内を追記
  - `docs/USER_GUIDE.md`: 設定画面の操作説明を更新
