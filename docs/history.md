NoCapEdit 正式版（v2系）のバージョンアップおよび仕様変更の履歴です。
新しいバージョンを上に記載しています。

> [!NOTE]
> - 本バージョン（v2.10.3）は、これまでのベータ版（v0.2系）の開発実績（10回の新機能追加および各種不具合修正・改善）をセマンティックバージョニング（SemVer）に基づいて正式版として換算・昇格させたものです。
> - Ver 0.2系（v0.2.0〜v0.2.34）の開発履歴は本ドキュメントの下部に継続して記載しています。
> - Ver 0.1系の改定履歴については、[Ver 0.1系 改定履歴 (history_v0.1.md)](history_v0.1.md) を参照してください。

## 改定履歴一覧

### Ver 2.13.0 | 2026-10-05 | yasudajs
- **拡張子別ファイルアイコン機能の追加（全47拡張子対応）**
  - **視認性に優れた拡張子別専用アイコン**: NoCapEdit に関連付け可能なすべての拡張子（全47種）に対し、Windowsエクスプローラー一覧で一目でファイル種別を識別できるよう、ファイルアイコン（`document.png`）の下部に拡張子名と色分け帯バナーを表示する専用マルチ解像度アイコン（ICO）を新設
  - **下部2段分バナースタイル＆中央配置デザイン**: 書類下部の下から2段目の罫線から底辺まで（高さ約117px）にカテゴリ別カラーの角丸帯バナーを配置し、大文字テキストを帯の上下左右完全中央（`anchor='mm'`）に太字（Segoe UI Black）で配置。文字サイズを最大化（2文字96px、3文字94px、4文字78px）し、中アイコン（48px）や小アイコン（32px）表示でも明瞭な視認性を実現
  - **カテゴリ別カラーリング**: 表計算・データ（CSV/TSV: Excelグリーン）、一般テキスト・ログ（TXT/LOG: スレートグレー）、Markdown（MD: スカイブルー）、データ・設定（JSON/YAML/XML/INI: オレンジ・アンバー・ティール）、専用形式（NCTX/NCMD: ブランドレッド・ワイン）、Web・プログラミング言語（HTML/CSS/JS/TS/PY/RS/GO/JAVA/C/CPP/CS/PHP/RB/SQL/SH/PS1等: 各公式カラー）を網羅
  - **アイコン自動生成ツール**: 512x512の原画からWindows標準の全6解像度（256x256, 128x128, 64x64, 48x48, 32x32, 16x16）を含むマルチ解像度ICOおよびPNGを一括自動生成するビルドスクリプト（`scripts/generate_document_icons.py`）を新設。同義拡張子（.yaml/.yml, .txt/.text, .py/.pyw 等）はアイコンファイルを共有して効率化（38種ICO）
  - **NSISインストーラー連携・関連付け強化**: インストーラー（`nsis/installer.nsi`）において各拡張子専用のProgID（`NoCapEdit.csv`, `NoCapEdit.txt` 等）を登録し、それぞれの専用アイコンを関連付け。エクスプローラーの「プログラムから開く」候補（`OpenWithProgids`）や既定のアプリ設定にも完全対応。アンインストール時の全アイコンおよびProgID削除クリーンアップ処理を実装

### Ver 2.12.1 | 2026-10-05 | yasudajs
- **行数表示時の境界線余白削除およびルーラー位置整合化**
  - **行数表示時の左余白最適化**: 行番号表示時にエディタ本文左側に存在していた `16px` の余白を `0px`（無し）に変更し、行番号境界線（ガター右端の縦線）の直後からテキストが開始されるよう改善
  - **ルーラー0桁目・境界線の完全整合**: 行番号表示時、ルーラーのスペーサー境界線および目盛り「0」（赤いカレットインジケータ含む）が行番号境界線と一直線に揃うよう連動修正。段差の違和感を解消
  - **行数非表示時の余白維持**: 行番号非表示時は従来どおり画面左端から `16px` の余白を維持し、テキストが画面端に密着しない安全なマージンを確保
  - **選択行ハイライト等の表示改善**: 行数表示時、選択行ハイライト（`.cm-selectionBackground`）が行数境界線から途切れず綺麗に描画されるよう改善

### Ver 2.12.0 | 2026-10-04 | yasudajs
- **名前をつけて保存機能（Ctrl + Shift + S）の追加**
  - **Windows標準「名前をつけて保存」ダイアログ連携**: ショートカットキー `Ctrl + Shift + S` により、Windows標準の保存ダイアログ（Common Item Dialog）を表示。ダイアログ内で新規フォルダを作成して整理したり、別ドライブや外部ストレージへの自由な保存に対応
  - **初期フォルダ・初期ファイル名のスマート設定**: 未保存の新規タブではアプリ設定のホームフォルダと日時タイムスタンプ名（`yyyymmdd_hhmmss.nctx`）を初期値としてセット。すでにディスクに存在するファイルでは現在のフォルダ・ファイル名を初期値として適用
  - **ファイルの種類（拡張子フィルター）**: `NoCapEdit Text (*.nctx)`（デフォルト）、`Text Files (*.txt)`、`CSV Files (*.csv)`、`すべてのファイル (*.*)` をサポート。ダイアログ上で拡張子を変更して保存（`.nctx` から `.txt` や `.csv` などへ変更）可能
  - **保存後ライフサイクルと安全性の確保**: 元ファイルはそのまま保持（複製・別名保存）し、タブの対象ファイルパスおよび表示名を新ファイルへ切り替え。拡張子に応じたシンタックスハイライトへ自動更新し、以降の自動保存・手動保存も新ファイルへ同期
  - **マウスカーソル非表示対策＆非同期化（フリーズ防止）**: Rust 側に親ウィンドウ（HWND）を明示的に紐付ける非同期ダイアログコマンド `show_save_dialog` を新設（UIフリーズ防止）。さらに Win32 API（`SetCursorPos`）によりダイアログ表示時にカーソル位置を再セットしてOSの「文字入力中のポインター非表示」状態を強制解除し、ダイアログ上でマウスカーソルが確実に可視化されるよう恒久対策を実施
  - **ヘルプ画面・ドキュメント更新**: ショートカットヘルプ画面（`F1` / `help.html`）、`SHORTCUTS.md`、`spec.md` に操作説明と仕様を追記

### Ver 2.11.1 | 2026-10-04 | yasudajs
- **不可視文字プラグインおよびインデントガイドの長大行描画例外・重複修正**
  - **長大行における例外停止の解消**: 折り返しOFFでの長大行（約4,000文字超）や折り返しONでの超長大行（約20,000文字超）において、CodeMirror 6 の描画最適化（line gap）により `visibleRanges` が同一行で複数区間に分割された際、不可視文字描画（`invisibleCharactersPlugin`）が `RangeSetBuilder` のソート順違反例外（`Ranges must be added sorted`）で停止する不具合を修正。走査範囲を表示区間 `[from, to]` のみに限定して昇順制約を厳密に保証
  - **改行記号の適切な追加判定**: 行末が現在の可視区間に含まれる場合（`line.to <= to`）にのみ改行記号 Widget を追加するよう判定を最適化
  - **インデントガイドの重複登録防止＆計算スキップ**: `indentGuidesPlugin` において、同一行分割時のインデントガイド Widget 二重追加を防止し、画面外行頭の不要なインデント計算探索をスキップするガード条件（`line.from >= from`）を追加してパフォーマンスを向上

  - **テーマ調和（透過率の最適化）**: カラーテーマ（Dark: 22%, Soft Dark: 15%, Light: 13%）に自動連動するCSS変数 `--invisible-char-color` を定義し、背景に自然に溶け込む視認性の高い控えめな配色を実現
  - **ヘルプ画面およびドキュメント更新**: F1キーのショートカットヘルプ画面（`help.html`）、`SHORTCUTS.md`、`USER_GUIDE.md`、`spec.md` に不可視文字表示機能の仕様と操作説明を追記
