# i18n リファクタリング Step 1.3: editor.js の多言語化対応 ウォークスルー

## 概要
エディタ領域のプレースホルダーおよびステータスバーのメトリクス表示（行、列、文字数など）を多言語化対応し、言語ごとの語順の違いを吸収できるようにしました。

## 変更内容
1. **`i18n.js` のテンプレート変数対応**
   - `window.t(key, params)` 関数を拡張し、第2引数で渡されたオブジェクトのキーと値を使って、文字列内の `{変数名}` を動的に置換する機能を追加しました。
   - `editor.metrics` 配下に、変数を含む日本語フォーマット（例: `"{line}行, {col}列"`）を定義しました。

2. **プレースホルダーの動的セット (`main.js`, `index.html`)**
   - `index.html` にハードコードされていた `<textarea>` の `placeholder` 属性を削除しました。
   - `main.js` の初期化処理 (`init()`) 完了時に、`t('editor.placeholder')` の戻り値を `elements.editor.placeholder` にセットするように変更しました。

3. **メトリクス文字列の置換 (`editor.js`)**
   - 変更前: `` `Ln ${line}, Col ${col}` `` のようにテンプレートリテラルで直接結合していた処理を廃止。
   - 変更後: `t('editor.metrics.position', { line, col })` のように `t()` 関数へ変数を渡し、辞書側のフォーマットに従って文字列を構築するように修正しました。
   - その他、文字数（全文字数、選択中の文字数）、フォントサイズ、行間についても同様に対応しました。
