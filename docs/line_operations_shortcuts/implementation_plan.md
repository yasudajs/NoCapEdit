# 行操作系ショートカット追加の実装計画書

## 概要
エディタでのメモ・テキスト編集を格段に効率化するため、以下の「行操作系ショートカット」を実装します。
単一行の操作はもちろん、複数行を範囲選択している場合でもブロック単位でスムーズに動作させます。

1. **行の上下移動 (Move Line Up/Down)**:
   - **`Alt + ↑`**: 現在の行（または選択行）を**1行上**に移動
   - **`Alt + ↓`**: 現在の行（または選択行）を**1行下**に移動
2. **行の上下複製 (Duplicate Line Up/Down)**:
   - **`Alt + Shift + ↑`**: 現在の行（または選択行）を**直上**に複製
   - **`Alt + Shift + ↓`**: 現在の行（または選択行）を**直下**に複製
3. **行の削除 (Delete Line)**:
   - **`Ctrl + Shift + K`**: 現在の行（または選択行）を行ごと一括削除

## 変更内容の詳細

### 1. エディタ操作モジュール (`src/dist/js/ui/editor.js`)
- 行操作ロジック関数を新設・実装：
  - `duplicateLine(direction)` : `direction = 'down' | 'up'`
    - 選択範囲を含む行全体のテキストブロックを取得
    - 直下または直上に複製し、カーソル・選択範囲を適切に追従
  - `deleteLine()` :
    - 選択範囲を含む行全体（改行を含む）を削除
    - 削除後の行位置へカーソルを調整
  - `moveLine(direction)` : `direction = 'down' | 'up'`
    - 上下の隣接行と選択行ブロックを入れ替え
    - 最上行での上移動、最下行での下移動は安全に無視
    - カーソル・選択範囲を移動後の行ブロックへ追従
  - いずれの操作後も `editor.dispatchEvent(new Event('input'))` を発火させ、文字数カウントや自動保存を連動させる。

### 2. ショートカット監視 (`src/dist/js/ui/shortcuts.js`)
- `editor.js` から行操作関数をインポート。
- `keydown` イベントリスナーにキー判定を追加：
  - `e.isComposing`（IME変換中）のガード処理
  - `Alt + Shift + ArrowUp` / `Alt + Shift + ArrowDown` → 行の複製
  - `Alt + ArrowUp` / `Alt + ArrowDown` → 行の上下移動
  - `Ctrl + Shift + KeyK` → 行の削除
  - 各操作時に `e.preventDefault()` を実行。

### 3. 多言語定義 (`src/dist/i18n.js`)
- `help.shortcuts` に以下を追加：
  - `duplicateLineDown`: `"行を下に複製"`
  - `duplicateLineUp`: `"行を上に複製"`
  - `deleteLine`: `"行を削除"`
  - `moveLine`: `"行を上下に移動"`

### 4. ヘルプ画面 (`src/dist/help.html`)
- 「ファイル・タブ操作」または新設の「テキスト編集」カテゴリに上記ショートカット一覧を追加。
