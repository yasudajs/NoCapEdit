# i18n 実装 — 手動テスト項目

## テスト前提
- ブランチ: `feature/i18n-implementation`
- `npm run dev` または `cargo tauri dev` でアプリを起動してテストする

---

## 1. 画面表示テスト（日本語テキストが正常に表示されるか）

### 1.1 初期表示・共通UI
- [x] アプリ起動後、サイドバーのヘッダー「ファイル」が正しく表示される
- [x] サイドバーの「フォルダ」パネルタイトルが正しく表示される
- [x] エディタのプレースホルダーテキストが正しく表示される
- [x] ステータスバーに「保存準備完了」等のステータスが正しく表示される
- [x] ツールバーの各ボタンのツールチップが正しく表示される（マウスホバーで確認）

### 1.2 タブ関連
- [x] 新しいタブを作成した際、「未保存」ラベルが正しく表示される
- [x] 未保存タブが複数ある場合、「未保存(2)」のようにカウント付きで表示される
- [x] タブの保存時に「保存中...」→「保存しました」のステータス遷移が正しく表示される

### 1.3 サイドバー — フォルダツリー
- [x] ホームフォルダが設定されていない場合、ヒントテキストが正しく表示される
    →　ホームフォールだの設定書を消去してから起動し、ホームフォルダがない状態から設定をしたとき、設定画面を閉じることが出来ない（要修正）
- [x] フォルダツリー展開時に「読み込み中...」が正しく表示される
- [x] 空フォルダを展開した際に「フォルダは空です」が正しく表示される
- [NG] フォルダ読み込みエラー時に「読み込みエラー: ...」が正しく表示される
    →　起動中にホームフォルダの名前を変えた場合、何もエラーが出ない（要修正）

### 1.4 サイドバー — ファイル/フォルダ操作
- [x] 右クリックコンテキストメニューの各項目（名前の変更、削除、コピー等）が正しく表示される
- [x] 新しいフォルダ作成時のデフォルト名「新しいフォルダ」が正しく表示される
- [x] 新しいファイル作成時のデフォルト名「名称未設定」が正しく表示される
- [x] 名前変更成功時のステータスメッセージが正しく表示される
- [-] 名前変更失敗時のエラーメッセージが正しく表示される
    → テスト方法がない
- [-] 作成失敗時のエラーダイアログが正しく表示される
    →　テスト方法がない

### 1.5 サイドバー — 削除操作
- [x] ごみ箱移動の確認ダイアログ「〇〇を削除してごみ箱に移動しますか？」が正しく表示される
- [x] 完全削除の確認ダイアログ「〇〇をごみ箱に入れず、完全に削除しますか？」が正しく表示される
- [x] 完全削除成功時に「完全に削除しました」が正しく表示される
- [x] 削除失敗時のエラーメッセージが正しく表示される
- [x] 空でないフォルダ削除時の「フォルダ削除エラー」ダイアログが正しく表示される

### 1.6 サイドバー — D&D / コピー / 切り取り / 貼り付け
- [x] ファイルをドラッグ&ドロップで移動した際、「移動中...」→「移動しました」のステータスが正しく表示される
    →　処理時間の問題か、「移動中...」は確認できず
- [NG] 自分自身へのドロップ時に「自分自身またはサブフォルダへは移動できません」が正しく表示される
    →　自分が存在するフォルダへドロップした場合、ファイルの枝番が増えていく現象が発見された（要修正）
- [x] コピー操作時に「〇〇をコピーしました」が正しく表示される
    →　文章を
- [x] 切り取り操作時に「〇〇を切り取りました」が正しく表示される
- [-] クリップボードが空の状態で貼り付けした際に「コピーまたは切り取りされたファイル/フォルダがありません」が正しく表示される
    →　クリップボードが空に出来なかったのでテストできず
- [x] 貼り付け成功時に「貼り付けが完了しました」が正しく表示される

### 1.7 設定関連
- [x] フォント設定のグループラベル（「等幅フォント」「その他」）が正しく表示される
- [x] フォント読み込み中のステータス「フォントを読み込み中...」が正しく表示される

### 1.8 ファイルシステム操作
- [-] リトライダイアログ（保存失敗時）が正しく表示される
    →　保存失敗自体を再現できず
- [x] ファイル名変更時のステータスが正しく表示される
