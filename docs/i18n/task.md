# i18n 実装 — 手動テスト項目

## テスト前提
- ブランチ: `feature/i18n-implementation`
- `npm run dev` または `cargo tauri dev` でアプリを起動してテストする

---

## 1. 画面表示テスト（日本語テキストが正常に表示されるか）

### 1.1 初期表示・共通UI
- [ ] アプリ起動後、サイドバーのヘッダー「ファイル」が正しく表示される
- [ ] サイドバーの「フォルダ」パネルタイトルが正しく表示される
- [ ] エディタのプレースホルダーテキストが正しく表示される
- [ ] ステータスバーに「保存準備完了」等のステータスが正しく表示される
- [ ] ツールバーの各ボタンのツールチップが正しく表示される（マウスホバーで確認）

### 1.2 タブ関連
- [ ] 新しいタブを作成した際、「未保存」ラベルが正しく表示される
- [ ] 未保存タブが複数ある場合、「未保存(2)」のようにカウント付きで表示される
- [ ] タブの保存時に「保存中...」→「保存しました」のステータス遷移が正しく表示される

### 1.3 サイドバー — フォルダツリー
- [ ] ホームフォルダが設定されていない場合、ヒントテキストが正しく表示される
- [ ] フォルダツリー展開時に「読み込み中...」が正しく表示される
- [ ] 空フォルダを展開した際に「フォルダは空です」が正しく表示される
- [ ] フォルダ読み込みエラー時に「読み込みエラー: ...」が正しく表示される

### 1.4 サイドバー — ファイル/フォルダ操作
- [ ] 右クリックコンテキストメニューの各項目（名前の変更、削除、コピー等）が正しく表示される
- [ ] 新しいフォルダ作成時のデフォルト名「新しいフォルダ」が正しく表示される
- [ ] 新しいファイル作成時のデフォルト名「名称未設定」が正しく表示される
- [ ] 名前変更成功時のステータスメッセージが正しく表示される
- [ ] 名前変更失敗時のエラーメッセージが正しく表示される
- [ ] 作成失敗時のエラーダイアログが正しく表示される

### 1.5 サイドバー — 削除操作
- [ ] ごみ箱移動の確認ダイアログ「〇〇を削除してごみ箱に移動しますか？」が正しく表示される
- [ ] 完全削除の確認ダイアログ「〇〇をごみ箱に入れず、完全に削除しますか？」が正しく表示される
- [ ] 完全削除成功時に「完全に削除しました」が正しく表示される
- [ ] 削除失敗時のエラーメッセージが正しく表示される
- [ ] 空でないフォルダ削除時の「フォルダ削除エラー」ダイアログが正しく表示される

### 1.6 サイドバー — D&D / コピー / 切り取り / 貼り付け
- [ ] ファイルをドラッグ&ドロップで移動した際、「移動中...」→「移動しました」のステータスが正しく表示される
- [ ] 自分自身へのドロップ時に「自分自身またはサブフォルダへは移動できません」が正しく表示される
- [ ] コピー操作時に「〇〇をコピーしました」が正しく表示される
- [ ] 切り取り操作時に「〇〇を切り取りました」が正しく表示される
- [ ] クリップボードが空の状態で貼り付けした際に「コピーまたは切り取りされたファイル/フォルダがありません」が正しく表示される
- [ ] 貼り付け成功時に「貼り付けが完了しました」が正しく表示される

### 1.7 設定関連
- [ ] フォント設定のグループラベル（「等幅フォント」「その他」）が正しく表示される
- [ ] フォント読み込み中のステータス「フォントを読み込み中...」が正しく表示される

### 1.8 ファイルシステム操作
- [ ] リトライダイアログ（保存失敗時）が正しく表示される
- [ ] ファイル名変更時のステータスが正しく表示される

---

## 2. 未翻訳チェック（キー名がそのまま表示されていないか）

- [ ] 画面上に `sidebar.` や `status.` 等のキー名がそのまま表示されている箇所がないか確認する
- [ ] ダイアログのタイトルに `dialog.error_title` 等のキー名が表示されていないか確認する

---

## 3. 回帰テスト（既存機能が壊れていないか）

- [ ] ファイルの新規作成・保存・読み込みが正常に動作する
- [ ] タブの切り替え・閉じる操作が正常に動作する
- [ ] フォルダツリーの展開・折りたたみが正常に動作する
- [ ] ドラッグ&ドロップによるファイル移動が正常に動作する
- [ ] コピー/切り取り/貼り付けが正常に動作する
- [ ] 設定の変更（フォント、テーマ等）が正常に動作する
