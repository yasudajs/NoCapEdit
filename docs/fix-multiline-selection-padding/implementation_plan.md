# 実装計画書: 複数行選択時における行頭左側余白の選択色描画解消

## 1. 概要
NoCapEdit において、テキストを複数行選択した際に行頭左側の余白部分（行番号ガターとテキストの間の16px領域）まで選択色（水色）が塗られてしまう不具合を修正します。
CodeMirror 6 の選択描画アーキテクチャに準拠した CSS / テーマ設定へ見直し、余白部分には選択色がつかず、テキストの開始位置から自然に選択ハイライトが描画されるように改善します。

---

## 2. 根本原因の分析
- **CodeMirror 6 の選択範囲描画 (`RectangleMarker` / `drawSelection`) の仕様**:
  複数行選択の中間行および終了行の矩形を計算する際、CodeMirror 6 は行の左端座標（`leftSide`）を以下のように算出します：
  $$\text{leftSide} = \text{contentRect.left} + \text{lineStyle.paddingLeft}$$
- **現在の設定**:
  - `src/frontend/style.css` および `src/frontend/js/ui/codemirror.js` において、エディタコンテンツ全体（`.cm-content`）に `padding: 16px` を設定し、各テキスト行（`.cm-line`）には `padding: 0` を設定しています。
  - そのため、CodeMirror はガター境界の座標を「行頭（`leftSide`）」と判定し、文字の手前にある 16px の余白部分まで選択色（`.cm-selectionBackground`）を描画してしまいます。
  - （※1行目/選択開始行は文字の描画位置から開始されるため、2行目以降の中間行・終了行のみ左側に凸凹にはみ出す現象が発生していました）

---

## 3. 修正内容

### 3.1 スタイルおよびテーマ設定の移行
余白（左右16px）の適用要素を `.cm-content` から各行である `.cm-line` に移行します。

1. **`src/frontend/style.css`**:
   - `.editor .cm-content` の `padding: 16px;` を `padding: 16px 0;`（上下のみ16px、左右は0）に変更。
   - `.editor .cm-line` の `padding: 0;` を `padding: 0 16px;`（左右に16px）に変更。
2. **`src/frontend/js/ui/codemirror.js`**:
   - `baseTheme` の `".cm-content"` の `padding: "16px"` を `padding: "16px 0"` に変更。
   - `baseTheme` の `".cm-line"` の `padding: "0"` を `padding: "0 16px"` に変更。

### 3.2 ルーラー計算ロジックの安全性向上
- **`src/frontend/js/ui/ruler.js`**:
  - ルーラーのガターオフセット計算関数 `getGutterOffset()` は現在 `coordsAtPos(0)`（1文字目の描画座標）を優先して使用しているため文字位置との完全同期が維持されますが、フォールバック計算（`.cm-line` の `getBoundingClientRect()` を参照する箇所）でも `.cm-line` の `paddingLeft` を加算するように補強し、安全性を高めます。

---

## 4. 影響範囲の確認
| 項目 | 影響・対応 |
|---|---|
| **テキスト・カーソル表示** | 左右の余白サイズ（16px）およびテキストの開始位置は全く同じであり、見た目の変化やズレはありません。 |
| **空行・カーソル移動** | 空行の行頭カーソル位置も `.cm-line` の padding 内側に正しく配置されます。 |
| **行番号表示 (ON/OFF)** | 行番号表示の有無に関わらず、余白部分には選択色がつかない挙動が一貫して保たれます。 |
| **行折り返し (Wrap)** | 各行 `.cm-line` 内でテキストが折り返されるため、左右16pxの余白を維持したまま折り返されます。 |
| **ルーラー・縦ガイド線** | 文字座標（`coordsAtPos(0)`）を元に0桁目を同期しているため、目盛り線や縦ガイド線の位置にズレは生じません。 |

---

## 5. 検証手順 (Verification Plan)
1. **複数行選択時の描画確認**:
   - 行番号が表示されている状態で、複数行（開始行、中間行、終了行）を選択する。
   - 行頭左側の余白（16px）に選択色（水色）が塗られず、テキストの開始位置から綺麗に選択色が塗られることを確認する。
   - 開始行、中間行、終了行の左端ラインが綺麗に揃うことを確認する。
   - 行末右側のエディタ端余白（16px）への不要なはみ出しがないことを確認する。
2. **行番号非表示時の描画確認**:
   - `Alt + L` で行番号を非表示にした状態で、同様に複数行選択を行い、左端余白に選択色がつかないことを確認する。
3. **ルーラーおよびカーソル位置の整合性確認**:
   - `Alt + R` でルーラーを表示し、0桁目の目盛り線が1文字目の左端と一致していることを確認する。
   - 任意桁にマーカー・縦ガイド線を設置し、文字と文字の間に正しく引かれることを確認する。
   - キャレット（カーソル）を行頭（0桁目）に置いた際、文字の直前に正常に表示されることを確認する。
4. **ビルド検証**:
   - `npm run build` を実行し、フロントエンドのビルドがエラーなく正常に通過することを確認する。
