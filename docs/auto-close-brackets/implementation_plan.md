# 実装計画書: 半角括弧・クォートの自動補完および改行時の閉じ括弧自動挿入機能

## 1. 概要・目的
プログラミング言語やテキスト編集時において、VS Code と同様の快適なコーディング体験を実現するため、以下の2つの機能を全ファイル形式（`.java`, `.js`, `.py`, `.rs`, `.txt`, `.nctx` 等）で標準機能として実装します。

1. **入力時の即時ペア補完（オートクローズ）**:
   - 半角の括弧・クォート6種（`{}`、`()`、`[]`、`""`、`''`、```` `` ````）を入力した際、閉じ文字を自動挿入し、カーソルを中央に配置する。
   - 閉じ文字のオーバータイプ（重複入力時のスキップ）、`Backspace` による空ペアの同時削除、選択範囲のペア囲みに対応する。
   - ※比較演算子（`a < b` 等）での誤爆を防ぐため、`<>` は自動補完対象外とする（VS Code標準準拠）。
2. **改行時（`Enter` 押下時）の3行目閉じ括弧展開・未閉じ `{` 自動補完**:
   - `{|}`、`(|)`、`[|]` のペア中央で `Enter` を押した際、2行目に1段深いインデントを入れてカーソルを配置し、3行目に現在行と同じインデントで閉じ括弧を展開する。
   - 既存の行などで直後に `}` がない `class Hello {` のような行末で `Enter` を押した際も、その `{` が未閉じであれば、2行目に1段深いインデントを入れてカーソルを配置し、3行目に現在行と同じインデントで `}` を自動挿入する（すでに後続行に対応する `}` がある場合は重複挿入せず、2行目のインデントのみ挿入する）。

### 3.1 フロントエンド依存関係の明記

- **変更内容**:
  - 現在推移的依存としてインストールされている `@codemirror/autocomplete` を、`package.json` の `dependencies` に明示的に追加します。

### 3.2 エディタ機能（オートクローズ・改行時閉じ括弧補完）の実装
- **対象ファイル**: [src/frontend/js/ui/codemirror.js](file:///d:/antigravity/NoCapEdit/src/frontend/js/ui/codemirror.js)
- **変更内容**:
  1. **即時ペア補完（`closeBrackets`）の統合**:
     - `@codemirror/autocomplete` から `closeBrackets` および `closeBracketsKeymap` をインポートします。
     - 言語定義（`LanguageSupport`）の有無にかかわらず、すべてのファイル形式（`.txt`, `.nctx` 含む）で6種類のペア（`()`, `[]`, `{}`, `""`, `''`, ```` `` ````）が自動補完されるよう、`EditorState.languageData.of(...)` でデフォルトの `closeBrackets` 設定（`brackets: ["(", "[", "{", "'", '"', "`"]`）を定義します。
     - `getDefaultExtensions` に `closeBrackets()` を追加し、キーマップに `...closeBracketsKeymap`（`Backspace` でのペア削除）を組み込みます。
  2. **括弧ペア間での改行展開（`isBetweenMatchingBrackets`）の強化**:
     - `{|}`、`(|)`、`[|]` のように隣接している場合だけでなく、`{ | }` のように括弧の間に空白文字（スペース・タブ）のみが存在する場合に `Enter` を押した際も、余分な空白を整理して2行目インデント＋3行目閉じ括弧へ綺麗に展開できるように拡張します。
  3. **未閉じ `{` の行末で改行した際の `}` 自動挿入ロジック**:
     - `customInsertNewlineAndIndent` において、カーソルが行末（カーソル以降が空白のみ）にあり、かつカーソル直前の非空白文字が `{` である場合を検出します。
     - **未閉じ `{` 判定関数 (`isUnclosedOpenBrace`)**:
       - ドキュメント内の `{` と `}` のバランスおよび後続行のインデント階層を検査し、現在の行の `{` に対応する閉じ `}` がまだ存在しない（未閉じである）かどうかを判定します。
     - **未閉じの場合**:
       - 2行目に `baseIndent + unit`（1段深いインデント）を挿入してカーソルを配置し、3行目に `baseIndent + "}"` を自動挿入します。
     - **すでに閉じ `}` が存在する場合**:
       - `}` は重複挿入せず、2行目に `baseIndent + unit`（1段深いインデント）のみを挿入します（これにより `.txt` や `.nctx` 等の構文定義を持たないファイルでも `{` 直後の改行で1段深いインデントが入るようになります）。

## 4. 検証計画
1. **ビルド検証**:
   - `npm run build` によりフロントエンドのバンドルビルドがエラーなく完了することを確認します。
2. **動作検証**:
   - **即時ペア補完**:
     - `.java` 等のコードファイルおよび `.txt` / `.nctx` ファイルにて、`{`, `(`, `[`, `"`, `'`, `` ` `` を入力した際に閉じ文字が自動挿入され、カーソルが中央に配置されること。
     - 直後に閉じ文字をタイプした際に重複せずスキップ（オーバータイプ）されること。
     - 空のペア中央で `Backspace` を押した際に両方の文字が同時に削除されること。
     - `<` を入力した際には `>` が自動挿入されないこと。
   - **改行時の3行目展開・自動挿入**:
     - `class Hello {` と入力して `{|}` となった状態で `Enter` を押した際、2行目にインデント＋カーソル、3行目に `}` が配置されること。
     - 既存の `class Hello {`（後ろに `}` がない状態）の行末で `Enter` を押した際も、2行目にインデント＋カーソル、3行目に `}` が自動挿入されること。
     - すでに3行目に `}` がある状態で1行目の `{` の直後で再度 `Enter` を押した際は、`}` が重複して増えず、インデントされた空行のみが挿入されること。
     - `Ctrl + Z`（Undo）で改行および自動挿入が1ステップで元に戻ること。
     - 日本語IME入力・変換中に干渉や誤動作が起きないこと。
