# 検索・置換（Find & Replace）機能 実装計画書

## 概要
エディタ内のテキストを素早く検索・置換できるよう、**エディタ組み込みの「検索・置換バー（フロートUI）」** を実装します。
1件ずつの置換とテキスト全体の一括置換（すべて置換）をサポートし、ブラウザ標準の Undo/Redo（`Ctrl + Z`）とも完全連動します。

---

## UIデザイン＆操作仕様

### フロートバーのレイアウト（エディタ右上配置）
```
┌─────────────────────────────────────────────────────────────┐
│ 🔍 [ 検索文字列...        ] [Aa]  [ ↑ ] [ ↓ ]  [ 1 / 8 件 ] [✕] │
│ 🔄 [ 置換文字列...        ]       [ 置換 ]    [ すべて置換 ]    │
└─────────────────────────────────────────────────────────────┘
```

| 項目 / ボタン | ショートカット | 挙動 |
|---|---|---|
| **検索を開く** | **`Ctrl + F`** | 検索バーを開き、検索語句入力欄にフォーカス（選択中テキストがあれば自動入力） |
| **置換を開く** | **`Ctrl + H`** | 置換バーを展開し、置換語句入力欄にフォーカス |
| **次を検索** | **`Enter`**（検索欄）/ **`↓` ボタン** | 次の一致箇所へジャンプして範囲選択 |
| **前を検索** | **`Shift + Enter`** / **`↑` ボタン** | 前の一致箇所へジャンプして範囲選択 |
| **1件置換** | **`Enter`**（置換欄）/ **[置換] ボタン** | 現在の一致箇所を置換し、自動で次の一致箇所へ移動 |
| **すべて置換** | **`Alt + A`** / **[すべて置換] ボタン** | テキスト内の全一致箇所を一括置換（1回のUndoで元に戻せる） |
| **大文字小文字の区別** | **[ Aa ] ボタン** | 大文字・小文字を厳密に区別するかトグル切り替え |
| **閉じる** | **`Esc`** / **[ ✕ ] ボタン** | バーを閉じ、**エディタの直前のカーソル位置へ即座に復帰** |

## 変更内容の詳細

### 1. HTML構造 (`src/dist/index.html`)
- エディタコンテナ内にフロート式の `#findReplaceWidget` を追加：
  - 検索行: 検索入力欄、大文字小文字トグルボタン、一致件数表示（例: `3 / 12`）、前へボタン、次へボタン、閉じるボタン
  - 置換行: 置換入力欄、1件置換ボタン、すべて置換ボタン

### 2. スタイル設計 (`src/dist/style.css`)
- エディタ右上に配置されるコンパクトなフローティングカードデザイン。
- Dark / Soft Dark / Light 各テーマの背景色・枠線・アクセントカラーに自動適応。
- `:focus-visible` スタイルによるキーボード操作時の明確なフォーカス表示。

### 3. 検索・置換ロジック (`src/dist/js/ui/findReplace.js`) [NEW]
- `openFind(focusReplace = false)`: バーを表示し、テキスト選択中ならその文字列を検索欄にセット。
- `closeFind()`: バーを非表示にし、エディタにフォーカス復帰。
- `findNext()` / `findPrev()`: `textarea` 内のマッチ位置を計算し、`setSelectionRange()` で選択＆スクロール。
- `replaceCurrent()`: `applyEditorTextWithUndo` を経由して現在マッチを置換し、次へジャンプ。
- `replaceAll()`: 全マッチを一括置換（`applyEditorTextWithUndo` 経由でUndoスタックを1件に集約）。
- `setupFindReplaceEvents()`: 入力変更時のリアルタイム件数更新、キーボードナビゲーション（Tab / Enter / Esc）。

### 4. ショートカット登録 (`src/dist/js/ui/shortcuts.js`, `src/dist/help.html`)
- `shortcuts.js`:
  - `Ctrl + F`: `openFind(false)`
  - `Ctrl + H`: `openFind(true)`
- `help.html`: 「テキスト編集」カテゴリに `Ctrl + F: 検索`, `Ctrl + H: 置換` を追加。

### 5. 多言語定義 (`src/dist/i18n.js`)
- `ui.find` セクション（プレースホルダー、ボタンツールチップ、件数表示テキスト）を追加。

## 検証計画

### 1. 検索機能の動作検証
- [ ] `Ctrl + F` を押すと検索バーが開き、検索欄にフォーカスが当たること
- [ ] テキスト選択中に `Ctrl + F` を押すと、選択中の文字列が検索欄に自動入力されること
- [ ] 検索語句を入力すると、一致件数（例: `1 / 5`）がリアルタイムに表示されること
- [ ] `Enter` / `Shift + Enter`（または `↓` / `↑` ボタン）で次 / 前の一致箇所へスムーズにジャンプ・選択されること
- [ ] [ Aa ] ボタンのON/OFFで大文字・小文字の区別が切り替わること

### 2. 置換機能の動作検証
- [ ] `Ctrl + H` を押すと置換バーが開き、置換欄にフォーカスが当たること
- [ ] 置換欄で `Enter`（または [置換] ボタン）を押すと、現在の一致箇所が置換されて次の一致箇所へ移動すること
- [ ] [すべて置換] ボタン（または `Alt + A`）を押すと、テキスト全体の全一致箇所が一括置換されること
- [ ] 置換後、`Ctrl + Z`（Undo）を押すと元のテキストに綺麗に戻ること（すべて置換も1回のUndoで復元）

### 3. キーボードナビゲーション＆エディタ復帰検証
- [ ] `Tab` / `Shift + Tab` で検索欄 ⇄ 置換欄 ⇄ 各ボタン間をスムーズに移動できること
- [ ] `Esc` キーを押すと検索・置換バーが閉じ、エディタの直前のカーソル位置へフォーカス復帰すること

### 4. ヘルプ画面検証
