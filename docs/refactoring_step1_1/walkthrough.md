# ウォークスルー: ステップ 1.1 設定管理ロジックの抽出

## 変更内容
1. **`src/settings.rs` の新規作成**
   - `main.rs` に存在していた `AppSettings`, `SettingsResponse` 構造体およびその実装 (`load`, `save`, `config_path` 等) を `settings.rs` に移動しました。
   - 初期値生成関数 (`default_theme` 等) や、設定ディレクトリに関する定数 (`APP_DIR_NAME`, `HOME_DIR_NAME`) も移行し、モジュール化しました。

2. **`src/main.rs` のリファクタリング**
   - 設定関連のコードを削除し、`mod settings;` を追加しました。
   - `settings::AppSettings` 等を利用するように既存コードを修正しました。
   - 使用されなくなった `Deserialize` のインポートを削除しました。

3. **ドキュメント・バージョンの更新**
   - バージョン番号を `0.1.49` にインクリメントしました（`Cargo.toml`, `tauri.conf.json`, `installer.nsi`, `DEVELOPMENT.md`）。
   - `docs/spec.md` を更新し、基本設定の管理を `settings.rs` で行う旨を記載しました。

## テスト・検証結果
* `cargo check` を実行し、エラーおよび警告がないことを確認しました（`Deserialize` 未使用の警告も解消済み）。
* 移行に伴うビルドエラーが発生しないことを確認しました。

## ユーザーへの確認事項
* モジュールの切り出しとビルドチェックは完了しました。
* 念のため、アプリを手動で起動していただき、以下の動作をご確認ください。
  1. アプリが正常に起動すること。
  2. 既存の設定（テーマなど）が維持されていること、または設定画面から変更・保存が機能すること。
