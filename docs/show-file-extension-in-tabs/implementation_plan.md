# タブ表示名におけるファイル拡張子表示対応 実装計画書

## 1. 概要
外部ファイルや手動保存ファイルを開いた際、従来の仕様では拡張子が非表示になっていたため、同名で拡張子が異なるファイル（例: `main.js`, `main.rs`, `main.css` 等）の判別が困難でした。
自動生成規則（`yyyymmdd_hhmmss.nctx`）に一致するファイルについては従来通り日時形式（`yyyy/mm/dd hh:mm:ss`）で表示し、それ以外のすべてのファイル（外部ファイルや明示的保存ファイル）については拡張子を省略せず、**`ファイル名.拡張子`**（例: `main.rs`, `memo.txt`, `README.md`）の形式でタブに表示するよう仕様を変更・実装します。

---

## 2. タブ表示名の仕様整理

| ファイルの種類 / 状態 | 自動保存モードでの表示 | 手動保存モードでの表示 |
| :--- | :--- | :--- |
| **未保存（ファイル未作成）** | `未保存N` | `[未保存N]` |
| **自動生成ファイル** (`20260827_011500.nctx`) | `2026/08/27 01:15:00` | `[2026/08/27 01:15:00]` |
| **自動生成ファイル（連番付き）** (`20260827_011500_1.nctx`) | `2026/08/27 01:15:00-1` | `[2026/08/27 01:15:00-1]` |
| **外部ファイル / 明示的保存ファイル** (`main.rs`) | `main.rs` | `[main.rs]` |
| **外部ファイル / 明示的保存ファイル** (`memo.txt`) | `memo.txt` | `[memo.txt]` |
| **拡張子なしファイル** (`Makefile` 等) | `Makefile` | `[Makefile]` |

---

## 3. 実装方針と変更内容

### 3.1 タブ表示名フォーマット処理の改修 (`src/frontend/js/ui/tabs.js`)
- `formatTabDisplayName(fileName)` 関数内の分岐において、`isAutoCreatedFileName(fileName)` に一致しないファイルは拡張子を削除する処理（`lastDotIdx` の切り落とし）を撤廃し、`displayName = fileName`（ファイル名＋拡張子そのまま）とする。
- 手動保存モード時の角カッコ付与処理（`[main.rs]`）はそのまま維持。

### 3.2 製品仕様書の更新 (`docs/spec.md`)
- §4.3「複数タブのサポート」内の「明示的な名前のファイル」に関する仕様記述を、拡張子付きで表示する旨に更新。

## 5. 検証手順

1. **自動生成ファイルの表示検証**:
   - 新規起動時および新規タブ（`Ctrl + T`）で入力して保存された際、`2026/08/27 01:15:00` のように日時形式で表示されることを確認。
2. **外部ファイル・明示的保存ファイルの表示検証**:
   - `Ctrl + O` やドラッグ＆ドロップで `main.js`, `main.rs`, `README.md`, `memo.txt` などを開いた際、タブに拡張子付きで正しく表示されることを確認。
   - 同名で拡張子の異なるファイル（例: `test.js` と `test.rs`）を開いた際、タブ上で明確に区別できることを確認。
3. **手動保存モードでの表示検証**:
   - 設定画面で「手動保存モード」に切り替えた際、`[main.rs]` や `[memo.txt]` のように角カッコ付きで正しく表示されることを確認。
