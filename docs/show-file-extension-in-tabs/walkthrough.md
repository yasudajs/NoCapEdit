# タブ表示名におけるファイル拡張子表示対応 ウォークスルー (Walkthrough)

## 1. 概要
NoCapEdit Ver 0.2.14 において、外部ファイルや明示的に保存したファイルを開いた際、タブ表示名に拡張子を含めてそのまま表示するよう改修を行いました。

---

## 2. 主な変更点と実装内容

### 2.1 タブ表示名フォーマット処理の改修 (`tabs.js`)
- `formatTabDisplayName(fileName)` 関数において、自動生成規則（`yyyymmdd_hhmmss.nctx`）以外のファイルに対する拡張子削除ロジックを撤廃し、`ファイル名.拡張子`（例: `main.rs`, `README.md`, `style.css`, `memo.txt` 等）をそのままタブ名として表示。
- 自動生成ファイル（`yyyymmdd_hhmmss.nctx`）はこれまで通り日時形式（`yyyy/mm/dd hh:mm:ss`）で表示。
- 手動保存モード時の角カッコ付与（例: `[main.rs]`）はそのまま維持。

### 2.2 製品仕様書および履歴の更新
- `docs/spec.md` の §4.3 タブ表示名仕様を拡張子付き表示へ改定。
- `docs/history.md` に Ver 0.2.14 の改定履歴を追記。
