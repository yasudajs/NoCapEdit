# ヘルプ画面下部の余白調整 実装計画書

## 概要
ヘルプ画面（ショートカット一覧）において、最下部までスクロールした際に最終行（「ヘルプを閉じる Esc」等）がウィンドウ下端に張り付いて読みにくくなっている問題を解消するため、下部に適切な余白（約30px〜40px / 1行分以上）を追加します。

---

## 変更内容の詳細

### 1. ヘルプ画面のスタイル調整 (`src/dist/help.html`)
- CSSスタイルに下部余白のスタイルを追加：
  - `body::after` 擬似要素または `.shortcut-list:last-of-type { margin-bottom: 30px; }` を指定し、スクロール最下部でも確実に1行分以上の余白が維持されるようにする。
  - `body` のパディングを `padding: 30px 30px 40px 30px;` に調整。

### 2. バージョン管理ファイルの更新（※作業開始時）
- バージョン番号を `0.1.78` から `0.1.79` に更新（4ファイル一括更新）：
  - `Cargo.toml`
  - `tauri.conf.json`
  - `nsis/installer.nsi`
  - `docs/DEVELOPMENT.md`
