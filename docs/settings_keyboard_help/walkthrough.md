# 設定画面キーボード操作ヘルプ拡充・ヒント表示 ウォークスルー (v0.1.88)

## 🎯 作業の目的・背景
NoCapEdit では、設定画面（`Ctrl + ,`）においてキーボードのみ（Tab、↑↓、Space、Escなど）で全項目の移動・変更・ダイアログ操作が完結する設計になっていますが、ヘルプ画面にはその操作方法が案内されておらず、キーボード操作の利便性が十分に伝わっていませんでした。

本作業では、ヘルプ画面への「設定画面の操作」カテゴリ新設、および設定ドック最下部への常時固定操作ヒント表示を実装しました。

---

## 🛠️ 実施した主な改修内容

### 1. ヘルプ画面（`help.html`）の拡充
- **「設定画面の操作」カテゴリを新設**:
  - 設定画面の開閉: `Ctrl + ,`
  - 設定項目の移動 (次へ): `Tab`
  - 設定項目の移動 (前へ): `Shift + Tab`
  - 設定値の選択・変更: `[↑] / [↓]`
  - フォルダ選択ダイアログを開く: `Space / Enter`
  - 設定を閉じてエディタに戻る: `Esc`
- **「その他」カテゴリにヘルプ起動キーを追加**:
  - ヘルプ画面を開く: `F1`
  - ヘルプを閉じる: `Esc`
  - アプリを終了: `Ctrl + Q`

### 2. 設定ドック（`index.html` / `style.css`）への常時固定ヒント追加
- 設定ドック（`#settingsDialog`）の `.dialog-content`（スクロール可能エリア）直下に、固定フッター要素（`.settings-footer`）を追加。
- 上部ボーダーとセカンダリテキストカラーによる落ち着いたデザインで、「`💡 Tab: 項目移動 │ ↑↓: 選択 │ Space: 実行 │ Esc: 閉じる`」を表示。
- 設定項目をスクロールしても、ヒント表示は画面下部に常に固定されます。

### 3. 多言語辞書（`src/dist/i18n.js`）の整備
- 新設カテゴリ名、各操作説明文、設定ドックのフッターヒント文を辞書キーとして定義し、多言語化アーキテクチャに準拠。

### 4. ドキュメントおよびバージョン更新
- `Cargo.toml`, `tauri.conf.json`, `nsis/installer.nsi`, `docs/DEVELOPMENT.md` のバージョンを `0.1.88` に更新。
- `spec.md`, `SHORTCUTS.md`, `history.md` を最新仕様に更新。
