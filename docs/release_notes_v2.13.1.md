## ✨ 主な更新内容 (Ver 2.13.1)

NoCapEdit のアップデート **v2.13.1** をリリースしました！🎉

本バージョンでは、行頭に全角スペースがある状態で改行した際に半角スペースに置き換わってしまう不具合を解消し、自動インデントの挙動を **VS Code 準拠** に刷新しました。
全角スペース、半角スペース、タブなどのインデント状態を文字種の変換なしにそのまま次の行へ維持できるようになり、日本語文書やメモの執筆がより自然で快適になりました。

---

### 🌟 主な改善点・修正内容

#### 1. 🔤 行頭全角スペースの改行時維持（半角スペース化不具合の解消）
- 行頭に全角スペース（`\u3000`）がある状態で `Enter` キーを押下した際、CodeMirror の内部処理（空白幅を数値換算してエディタ設定に従い再構築する仕様）によって半角スペースやタブに変換されてしまう不具合を修正しました。
- 前行の行頭にある全角スペースがそのまま次行の先頭に引き継がれるようになり、日本語の段落インデントなどを崩さずに執筆できます。

#### 2. ⚡ VS Code 準拠の自動インデントロジック
- 改行時の自動インデント処理を CodeMirror 標準依存から刷新しました。
- 前行の行頭にある空白文字列（全角スペース、半角スペース、タブ）を別の文字種に変換することなく、そのまま忠実に次行へ反映します。
- 半角スペースとタブが混在している場合や、半角スペース複数個のインデントもそのまま維持されます（設定値によって勝手にタブや別文字に変換されません）。

#### 3. 🎯 カーソル位置に応じた適切な改行制御
- **行頭（最先頭）での改行**: 上に空行を挿入し、既存行のインデントを維持します（VS Code準拠）。
- **インデント文字の途中での改行**: 文字間で分割して改行します。
- **空白のみの行での改行**: 空白インデントをそのまま次行へ維持します。
- **括弧ペア（`{}`、`[]`、`()`）間での改行**: 前行のインデントをベースに括弧展開（中間行の追加インデント）を行います。
- **IME・Undo/Redo**: 日本語IME変換中の確定Enterの誤爆防止ガード、および単一のUndo履歴（トランザクション）として安全に記録される設計です。
