# i18n リファクタリング Step 1.2: tabs.js 多言語化対応 ウォークスルー

## 概要
`src/dist/js/ui/tabs.js` 内にハードコードされていた日本語文字列をすべて抽出し、`i18n.js`（`window.t()`）経由での呼び出しに置き換えました。

## 変更内容
1. **多言語辞書の更新 (`src/dist/i18n.js`)**
   - `tabs` キーの配下に、`state`、`status`、`error` などのカテゴリを作成し、文字列を定義しました。
   - 例: `"保存中..."` -> `tabs.state.saving`

2. **UIコンポーネントの修正 (`src/dist/js/ui/tabs.js`)**
   - **正規表現の動的生成**: ファイル名が「未保存」から始まるかを判定する正規表現について、`t('tabs.unsaved.label')` を用いて動的に構築するように修正しました。
   - **ステータス表示の多言語化**: `updateStatus` や `updateTabStatus` 関数内で使用される「編集中」「保存準備完了」などの文字列を置換しました。
   - **エラーメッセージの多言語化**: ホームフォルダ未設定時や新規作成・タブ切り替え失敗時のエラーメッセージを置換しました。
   - **新規タブ名の生成**: 手動保存モード時と通常時の「未保存X」テキストを辞書ベースに置換しました。

## 動作確認結果
- 実行時のシンタックスエラーがないことを確認。
- （目視レビューによる確認）すべての `tabs.js` 内の日本語ハードコード箇所が `t()` 関数の呼び出しに適切に置き換わっており、既存ロジック（変数の埋め込み等）も正常に機能する形で組み込まれています。
