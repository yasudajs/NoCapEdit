# 初期空タブへのファイルオープン時の内容上書きバグ修正 ウォークスルー (Walkthrough)

## 1. 概要
NoCapEdit Ver 0.2.16 において、起動直後の未編集・未作成の初期空タブに対してファイル（CSVや各種テキスト）をドラッグ＆ドロップまたはファイル選択ダイアログで開いた際、ファイル内容が空エディタ状態で誤って上書きされ白紙になる不具合を修正しました。

---

## 2. 原因と改修内容

### 2.1 原因
- `openExistingFile` において、初期空タブを置換して開く際に `switchTab(firstTab.id)` を呼び出していました。
- `switchTab` の冒頭にあった「直前のエディタ状態の吸い出し・退避」処理が、切り替え前と切り替え先が同一タブID（`firstTab.id`）であったため実行されてしまい、画面上の古い空エディタ状態で新しく読み込んだファイル内容（`firstTab.editorState`）を空文字で上書きしていました。

### 2.2 改修内容
- `src/frontend/js/ui/tabs.js` の `switchTab(tabId)` において、`if (appState.currentTab && appState.currentTab !== tabId)` のガードを追加。
- これにより、同一タブIDに対する不要かつ危険なエディタ状態の吸い出し・退避処理をスキップし、読み込んだファイル内容がそのまま確実にエディタへ反映されるように修正。
