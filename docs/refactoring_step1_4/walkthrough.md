# ウォークスルー: ステップ 1.4 `main.rs` の軽量化と結合テスト

## 変更内容
1. **`src/cli.rs` の新規作成**
   - 起動時のコマンドライン引数を解析し、初期ロード対象のファイルパスを絶対パスで返す `parse_launch_file_arg` 関数を抽出しました。

2. **`src/theme.rs` の新規作成**
   - Windows 固有の DWM (Desktop Window Manager) API を用いてダークモードを適用するロジックを `apply_to_window` 関数として抽出しました。
   - `commands.rs` 内の `apply_theme` コマンドも、この共通関数を呼び出すようにリファクタリングしました。

3. **`src/main.rs` のリファクタリング**
   - 上記の抽出により、`main.rs` はモジュール定義（`mod`）の羅列と、Tauriの初期化・セットアップ（エントリーポイントとしての役割）のみを持つように大幅に軽量化されました。
   - ファイル行数も 107行 から約 80行 まで減少し、可読性が向上しました。

4. **ドキュメント・バージョンの更新**
   - バージョン番号を `0.1.52` にインクリメントしました（`Cargo.toml`, `tauri.conf.json`, `installer.nsi`, `DEVELOPMENT.md`）。

## テスト・検証結果
* `cargo check` を実行し、モジュール分割に伴うコンパイルエラーや警告がないことを確認しました。

## ユーザーへの確認事項
* モジュールの切り出しとビルドチェックは完了しました。
* **今回が「ステップ1：Rustバックエンドのモジュール化」の最終段階となります。**
* お手数ですが、アプリの基本機能がすべて正常に動作するか、以下の「結合テスト」をお願いいたします。
  1. 通常通りアプリが起動し、テーマが反映されていること。
  2. ターミナルから `cargo run -- "C:\適当なパス\ファイル.txt"` を実行し、ファイルが開かれること。
  3. その状態から別のターミナルで同じコマンドを実行した際、既存のウィンドウにフォーカスが移り、新しいファイルが開かれること（単一インスタンス動作の確認）。
