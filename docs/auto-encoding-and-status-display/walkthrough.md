# 文字コード自動判定およびステータスバー文字コード表示対応 ウォークスルー (Walkthrough)

## 1. 概要
NoCapEdit Ver 0.2.15 において、Excel で出力された Shift_JIS (CP932) の CSV ファイルや様々な文字コードのテキストファイルを開いた際、自動的に文字コードを判定して正常に読み込む機能と、ステータスバー左側のファイル表示に文字コード名（例: `(Shift_JIS)`）を表示する機能を実装しました。

---

## 2. 主な変更点と実装内容

### 2.1 文字コード自動判定・デコード (Rust バックエンド)
- `encoding_rs` を導入し、ファイル読み込み時に以下の優先順で自動判定・デコード：
  1. BOM 判定 (UTF-8, UTF-16LE, UTF-16BE)
  2. UTF-8 (BOMなし) 厳格検証
  3. Shift_JIS (CP932) 検証・デコード
  4. EUC-JP 検証・デコード
  5. フォールバック (Shift_JIS 置換デコード / UTF-8 lossy)
- `read_text_file` コマンドからテキスト内容とともに判定された文字コード名（`UTF-8`, `Shift_JIS`, `EUC-JP`, `UTF-16LE` 等）を返却。

### 2.2 保存時の文字コード維持
- 既存の Shift_JIS ファイルを開いて編集・保存した際、元のエンコーディングを維持してディスクへ安全に保存。
- 新規自動生成ファイル（`yyyymmdd_hhmmss.nctx`）は常に UTF-8 で作成。

### 2.3 ステータスバー文字コード表示
- 各タブで `encoding` 状態を保持。
- ステータスバー左側のファイル表示に `(文字コード)` を付与（例: `sales.csv (Shift_JIS) - 保存済み`、`main.rs (UTF-8) - 編集中`）。

### 2.4 製品仕様書および履歴の更新
- `docs/spec.md` の §4.4 文字コード仕様および §4.5 ステータスバー表示仕様を更新。
- `docs/history.md` に Ver 0.2.15 の改定履歴を追記。
