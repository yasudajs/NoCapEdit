# マルチディスプレイ移動時のIMEインライン入力位置ずれ修正 実装計画書

## 1. 概要
マルチディスプレイ環境において、NoCapEdit のウィンドウを起動後に別のディスプレイ領域へ移動させた際、日本語入力（IME）のインライン入力（未確定文字列および変換候補ウィンドウの表示）がカーソル位置に追従せず、画面左上（`(0, 0)` 付近）に表示されてしまう不具合を解消します。

---

## 2. 原因とメカニズム
- **原因**:
  - Windows の IME（Text Services Framework: TSF）は、ウィンドウがフォーカスを取得したタイミングで、現在のアクティブウィンドウの絶対スクリーン座標とキャレット（カーソル）位置を取得して初期化します。
  - ウィンドウをフォーカスしたまま別ディスプレイへドラッグ移動すると、WebView2 / Chromium 内部で保持されているスクリーン座標と OS の TSF 間の座標同期が失われ、TSF がキャレット位置を見失って画面原点 `(0, 0)` にフォールバック表示してしまいます。
  - ユーザーが一度別ウィンドウをクリックして戻ると正常に戻るという事実から、**フォーカスの再同期（リフレッシュ）が走ることで座標が復元される**ことが確認されました。

---

## 3. レビュー指摘事項の反映と修正方針

レビュー（`review.md`）での確認・指摘事項を反映し、以下の詳細設計とします。

### 3.1 `resyncEditorPosition()` の配置と実装 (`codemirror.js`)
- `editorView` へのアクセスおよびライフサイクル管理を最も安全に行うため、再同期処理は `src/frontend/js/ui/codemirror.js` 内に実装・エクスポートします。
- **IME変換中のセーフガード**:
  - CodeMirror 6 標準の `editorView.composing` プロパティを利用してIME変換中かどうかを判定。
  - 変換中にウィンドウが移動された場合は、フラグ `pendingImeResync = true` をセットし、`initEditor` 内で `editorView.contentDOM` に登録した `compositionend` イベントリスナーにより変換確定直後に遅延実行します（変換途中でフォーカスが外れて入力が飛ぶ事故を防止）。
- **フォーカス再同期のタイミング**:
  - 環境依存を吸収するため、`editorView.contentDOM.blur()` 後に `setTimeout(..., 30)`（約30ms）で `editorView.focus()` および `editorView.requestMeasure()` を実行します。

### 3.2 ウィンドウ移動・スケール変更監視 (`main.js`)
- `src/frontend/js/main.js` にて、既存の `listen` API を用いて `tauri://move` および `tauri://scale-change` をリッスンします。
- ドラッグ移動中の高頻度発火を抑制するため、**150ms のデバウンス** を導入し、移動停止後に `resyncEditorPosition()` を呼び出します。

## 5. 検証手順

1. **マルチディスプレイでのウィンドウ移動検証（不具合解消の確認）**:
   - メインディスプレイで NoCapEdit を起動し、日本語を入力してインライン入力ができることを確認。
   - ウィンドウをマウスでドラッグしてセカンダリディスプレイへ移動。
   - 別ウィンドウをクリックせず、そのまま日本語を入力して、**画面左上ではなくカーソル直下にインライン入力枠・変換候補が表示されること**を確認。
2. **逆方向の移動検証**:
   - セカンダリディスプレイからメインディスプレイへウィンドウを移動し、同様に即座にインライン入力できることを確認。
3. **IME変換中の移動セーフガード検証**:
   - 日本語の未確定文字列（例: 「きょうのてんき」）を入力中にウィンドウを別ディスプレイへ移動させ、確定後にフォーカスが正常に維持され、次回の入力も正しい位置でインライン入力できることを確認。
4. **単一ディスプレイ環境での退行確認**:
   - 単一ディスプレイ上でのウィンドウ移動やリサイズ、文字入力において、入力の引っ掛かりやチラつき等の悪影響がないことを確認。
5. **自動テスト・ビルド**:
   - `cargo test` および `npm run build` がエラーなく正常完了することを確認。
