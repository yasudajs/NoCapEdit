# 指定行ジャンプ機能 (Ctrl+G) ウォークスルー (Ver 0.2.28)

## 1. 今回の変更概要
行番号表示機能（Ver 0.2.24）の追加に続き、長文やログ閲覧時の操作性を向上させるため、キーボードショートカット `Ctrl + G` で起動できる**指定行ジャンプ機能（Go to Line）**を実装しました。

エディタ右上にコンパクトなフロートウィジェットを展開し、正の行番号だけでなく、行末からの逆算ジャンプ（マイナス記号）、コロン区切りの列指定、不正入力時のリアルタイム赤枠＆エラー案内表示に対応しています。

---

## 2. 実装された機能詳細

### 2.1 UI配置と排他制御
- **エディタ右上フロートカード**: 検索・置換ウィジェットと同一位置（`top: 10px; right: 20px;`）に表示され、テキストの視界を塞ぎません。
- **検索バーとの排他連携**:
  - `Ctrl + G` を押した際、検索バー（`Ctrl + F`）が開いていれば検索バーを自動で閉じてジャンプバーを開きます。
  - 逆に `Ctrl + F` / `Ctrl + H` を押した際は、ジャンプバーを自動で閉じて検索バーを開きます。

### 2.2 入力フォーマットと柔軟なナビゲーション
1. **正の行番号（例: `15`）**: 1行目から数えて15行目の先頭へ移動。
2. **行末からの逆算指定（例: `-5`）**: 総行数 $N$ に対して $N - 5 + 1$ 行目へ移動（`-1` は最終行）。
3. **列指定（例: `15:10` / `-5:3`）**: 指定行の指定文字位置（列）へキャレットを移動。
   - 列番号が 0 以下の場合は 1 文字目にクランプ。
   - 行の長さを超える列番号が指定された場合は、行末位置に自動クランプ（丸め）。

### 2.3 バリデーションとリアルタイムエラー表示
- `0`、総行数を超える行番号、計算結果が0以下となるマイナス指定、数値以外の文字が入力された場合：
  - 入力欄の枠線を赤くハイライト（`--status-error`）
  - 入力欄下部にエラーメッセージ（「1 〜 {max} 行の範囲で指定してください」「有効な行番号を入力してください」）を赤文字でリアルタイム表示
  - エラー表示中は `Enter` キーや「ジャンプ」ボタンを押してもジャンプ処理は実行されず、ウィジェットを維持

### 2.4 キーボード操作性 & スクロール
- **`Ctrl + G`**: 開閉トグル。展開時は直前の入力文字列が全選択され、すぐに新しい数字を入力可能。
- **`Enter`**: バリデーション成功時に指定位置へジャンプし、ウィジェットを自動で閉じてエディタ本文へフォーカスを復帰。
- **`Esc` / ✕ボタン**: ジャンプをキャンセルしてウィジェットを閉じ、元のカーソル位置を維持。
- **画面中央スクロール**: ジャンプ先の行がエディタ画面の縦方向中央に来るようスムーズにスクロール（CodeMirror の `scrollIntoView(pos, { y: 'center' })`）。

### 2.5 多言語化 (i18n)
- ハードコード排除規約に従い、プレースホルダー、範囲案内、エラーメッセージ、ツールチップをすべて `src/frontend/i18n.js` にて定義。
