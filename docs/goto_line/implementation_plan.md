# 指定行ジャンプ機能 (Ctrl+G) 実装計画書

## 1. 概要
行番号表示機能の追加に伴い、指定した行番号（および列番号）へ瞬時にキャレットを移動・スクロールできる「指定行ジャンプ機能（Go to Line）」を実装する。
キーボードショートカット `Ctrl + G` によりエディタ右上にコンパクトな入力ウィジェットを表示し、正の行番号だけでなく「行末からの逆算指定（マイナス記号）」や「コロンによる列指定」にも対応する。

---

## 2. 仕様詳細

### 2.1 UI配置とデザイン
- **配置**: エディタ右上フロート（`top: 10px; right: 20px;`）。検索・置換ウィジェット（`#findReplaceWidget`）と同一エリア・同一デザイン言語を採用。
- **排他制御**:
  - `Ctrl + G`（行ジャンプ）起動時、検索バーが開いていれば検索バーを自動で閉じる。
  - `Ctrl + F` / `Ctrl + H`（検索・置換）起動時、行ジャンプバーが開いていれば行ジャンプバーを自動で閉じる。
- **ウィジェット構造**:
  - **入力欄**: テキストボックス（プレースホルダー: 「行番号を入力 (例: 15, -5, 10:5)」）
  - **現在の行範囲表示**: 「1 〜 {総行数}」のガイド表示
  - **ジャンプボタン**: 「ジャンプ」ボタン
  - **閉じるボタン**: 「✕」ボタン
  - **エラーメッセージ表示領域**: 入力欄の下部に配置（通常は非表示、エラー時のみ赤文字で表示）

### 2.2 入力フォーマットと解釈ルール
1. **行番号（正の整数）**:
   - 例: `10` → 1行目から数えて 10 行目の先頭へジャンプ。
2. **行末からの逆算指定（負の整数）**:
   - 例: `-1` → 最終行（総行数 $N$ に対して $N - 1 + 1 = N$ 行目）へジャンプ。
   - 例: `-5` → 行末から5行目（$N - 5 + 1$ 行目）へジャンプ。
3. **列指定（コロン区切り）**:
   - 例: `10:5` → 10行目の 5 文字目（列位置）へジャンプ。
   - 例: `-5:3` → 行末から5行目の 3 文字目へジャンプ。
   - **列番号のクランプ**: 指定された列番号が 1 未満の場合は 1 文字目へ、該当行の行末文字数を超える場合は行末位置へ自動クランプ（丸め）する。

### 2.3 バリデーションとエラー表示
- 以下の条件に合致する場合を「無効な入力」と判定する：
  - 数字（および先頭のマイナス、途中の単一コロン）以外の不正な文字が含まれる場合。
  - 行番号が `0` の場合。
  - 正の行番号が総行数 $N$ を超えている場合（`line > N`）。
  - 負の行番号の計算結果が 0 以下となる場合（$N - |line| + 1 \le 0$）。
- **エラー時の挙動**:
  - 入力欄の枠線を赤色（`--status-error` / `#f44336` 等）にハイライト。
  - 入力欄の下部にエラーメッセージ（例: 「1〜{max}行の範囲で指定してください」など）を赤文字でリアルタイム表示。
  - エラー状態では `Enter` キー押下やジャンプボタン押下によるジャンプ処理を実行せず、ウィジェットも閉じない。

### 2.4 キーボード操作とライフサイクル
- **`Ctrl + G`**:
  - 行ジャンプウィジェットを開く（すでに開いている場合は閉じるトグル動作）。
  - 開いた際、直前の入力値がある場合は全選択状態にし、即座に新しい数字をキー入力できるようにする。
  - ウィジェットを開いた瞬間にテキストボックスへ自動フォーカス。
- **`Enter`**:
  - バリデーションが正常であれば、指定行・列へジャンプを実行。
  - ウィジェットを自動で閉じ、エディタ本文へフォーカスを復帰させる。
- **`Esc` / 閉じるボタン（✕）**:
  - ジャンプをキャンセルし、ウィジェットを閉じる。
  - 元のカーソル位置・選択状態を維持したまま、エディタ本文へフォーカスを復帰させる。
- **スクロール位置**:
  - ジャンプ先の行がエディタ画面の **中央（縦方向の中央）** に来るようにスムーズにスクロールする（CodeMirror の `scrollIntoView: true` / `{ y: 'center' }` 相当）。

### 2.5 多言語対応 (i18n)
- `src/frontend/i18n.js` に日英の翻訳キーを定義（ハードコード排除規約を遵守）：
  - プレースホルダー（`goto.placeholder`）
  - ツールチップ（`goto.title`, `goto.close`）
  - ジャンプボタン文言（`goto.jump`）
  - エラーメッセージ各種（`goto.error.range`, `goto.error.invalid`）
  - ヘルプ項目・ショートカット説明（`help.shortcuts.gotoLine`）

## 4. 検証計画（テスト項目）

1. **基本ジャンプ動作**:
   - 正の行番号（1行目、中間行、最終行）を入力して `Enter` でジャンプすること。
   - ジャンプ後の行がエディタ画面の中央付近に表示されること。
   - ジャンプ後にウィジェットが閉じ、エディタにフォーカスが戻っていること。
2. **マイナス（行末からの逆算）ジャンプ**:
   - `-1` を入力して最終行へジャンプすること。
   - `-5` を入力して末尾から5行目へジャンプすること。
3. **列指定ジャンプ**:
   - `10:5` を入力して 10行目の5文字目にキャレットが置かれること。
   - 列数が大きすぎる場合（例: 20文字の行に `10:100`）、行末文字にクランプされること。
   - 列数が 0 以下の場合は 1文字目にクランプされること。
4. **バリデーション & エラー表示**:
   - `0`、総行数を超える数値、総行数を超えるマイナス（例: 100行に対して `-150`）、英字等を入力した際に入力枠が赤くなり、エラーメッセージが表示されること。
   - エラー表示中は `Enter` を押してもジャンプせずウィジェットが閉じないこと。
5. **キーボード・UI操作性**:
   - `Ctrl + G` で開閉（トグル）できること。
   - 再度開いた際に入力テキストが全選択されていること。
   - `Esc` または ✕ボタンでキャンセルして閉じ、元のカーソル位置が維持されること。
   - `Ctrl + F`（検索）と相互に排他動作（片方を開くと他方が閉じる）すること。
6. **多言語 & ビルド**:
   - 言語切替時にもプレースホルダーやエラー文が正常に切り替わること。
   - `npm run build` および `cargo check` 等がエラーなく完了すること。
