# Tauri v1.6 アップデート計画

Tauri v1.5系 から最新の v1.6系 へのアップデートを行います。

## 調査結果概要
Tauri v1.5 から v1.6 へのアップデートは「マイナーバージョンアップ」であり、**アーキテクチャの変更や破壊的変更はありません**。
主に安定性の向上やバグ修正が含まれています。
コードの書き換え等は発生せず、バージョン指定の変更のみで安全に移行可能です。

## 変更内容
### Cargo.toml
Rustプロジェクトの依存関係のバージョン指定を更新します。
- [dependencies] の 	auri を ersion = "1.6" に変更
- [build-dependencies] の 	auri-build を ersion = "1.6" に変更
