# Tauri v1.6 アップデート ウォークスルー

## 概要
NoCapEdit プロジェクトの Tauri バックエンドフレームワークを、v1.5 系から最新の v1.6 系にアップデートしました。
このアップデートはマイナーバージョンアップであるため、アーキテクチャの変更や既存のフロントエンド（`window.__TAURI__` の呼び出し等）に対する破壊的変更はなく、安全に完了しています。

## 実施した変更
- **バージョン番号の更新**: アプリケーションのバージョンを `0.1.94` に更新しました。
  - `Cargo.toml`
  - `tauri.conf.json`
  - `nsis/installer.nsi`
  - `docs/DEVELOPMENT.md`
- **依存関係の更新**:
  - `Cargo.toml` において `tauri = { version = "1.6", ... }` および `tauri-build = { version = "1.5", ... }` に設定。
  ※ `tauri-build` クレートは 1.6 がリリースされていないため、引き続き 1.5.x を使用しています。
  - `cargo update -p tauri` を実行し、`Cargo.lock` を更新しました。

## 検証結果
- `cargo check` を実行し、Tauri 1.8.3 (1.x 系の最新マイナーパッチ) が正常にダウンロードされ、コンパイルエラーなくビルド可能であることを確認しました。
- 破壊的変更がないため、これまでの機能に影響はありません。
