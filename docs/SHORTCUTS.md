# ⌨️ キーボード操作 & ショートカット一覧 (Shortcuts)

NoCapEdit で利用できるキーボードショートカットとマウス操作の一覧です。
キーボードのみで効率的に執筆やファイル操作を行えるように設計されています。

> [!TIP]
> アプリケーションの基本的な画面構成や使い方については、[ユーザーガイド](USER_GUIDE.md) をご参照ください。

---

## 📝 エディタ操作
テキスト入力・編集エリアでの操作です。

| ショートカットキー | 操作内容 | 備考 |
| :--- | :--- | :--- |
| `Ctrl` + `S` | **手動保存** | 自動保存モード時でも、即座にディスクへ書き込みます。 |
| `Alt` + `↑` <br> `Alt` + `↓` | **行の上下移動** | 現在行（または選択中の複数行）を上下に1行移動します。 |
| `Alt` + `Shift` + `↑` <br> `Alt` + `Shift` + `↓` | **行の上下複製** | 現在行（または選択中の複数行）を直上または直下に複製します。 |
| `Alt` + `Shift` + `K` | **行の削除** | 現在行（または選択中の複数行）を行ごと一括削除します。 |
| `F5` | **現在日時の挿入** | カーソル位置に現在日時（`YYYY/MM/DD HH:mm`）を挿入します。 |
| `Ctrl` + `F` | **検索バーを開く** | 検索バーを表示し、キーワード検索を行います（`Enter` で次へ、`Shift+Enter` で前へ、`Esc` で復帰）。 |
| `Ctrl` + `H` | **置換バーを開く** | 置換バーを展開し、1件置換（`Enter`）やすべて置換（`Alt+A`）を行います。 |
| `Ctrl` + `+` <br> `Ctrl` + `-` <br> `Ctrl` + `マウスホイール` | **文字サイズの拡大・縮小** | エディタの文字サイズを変更します（8pt 〜 72pt）。 |
| `Ctrl` + `Shift` + `+` <br> `Ctrl` + `Shift` + `-` <br> `Ctrl` + `Shift` + `マウスホイール` | **行間の拡大・縮小** | エディタの行間を変更します（1.0倍 〜 3.0倍）。 |
| `Ctrl` + `0` | **ズーム・行間のリセット** | 文字サイズ（20pt）と行間（1.5倍）をデフォルト値に戻します。 |
| `Alt` + `Z` | **行の折り返し切り替え** | 現在のタブの折り返し（ON/OFF）を一時的に切り替えます。 |
| `Tab` | **インデントの挿入** | 設定で選択されたインデント（タブ文字、スペース2/4文字）を挿入します。<br>複数行を選択している場合は、選択したすべての行頭にインデントを挿入します。 |
| `Shift` + `Tab` | **インデントの削除** | 選択行（または現在行）の行頭からインデントを1段階削除します。 |

## 🗂 タブ操作
開いているファイルの切り替えや操作です。

| ショートカットキー | 操作内容 | 備考 |
| :--- | :--- | :--- |
| `Ctrl` + `T` | **新しいタブを開く** | プラス（`+`）ボタンを押した時と同様に、新規タブを作成して切り替えます。 |
| `Ctrl` + `W` | **現在のタブを閉じる** | アクティブなタブを閉じます。最後の1つを閉じた場合は自動で新しい空タブが開きます。 |
| `Ctrl` + `Tab` | **右隣のタブへ移動** | 一番右端のタブで押した場合は、先頭（一番左）のタブに戻ります。 |
| `Ctrl` + `Shift` + `Tab` | **左隣のタブへ移動** | 先頭（一番左）のタブで押した場合は、末尾（一番右）のタブに戻ります。 |

## ⚙️ 設定画面の操作
設定画面（右ドック）内のキーボード操作です。

| ショートカットキー | 操作内容 | 備考 |
| :--- | :--- | :--- |
| `Ctrl` + `,` | **設定画面の開閉** | 設定ドックを開閉します（トグル操作）。 |
| `Tab` | **設定項目の移動 (次へ)** | 次の設定項目へフォーカスを移動します（末尾の次は先頭へ循環）。 |
| `Shift` + `Tab` | **設定項目の移動 (前へ)** | 前の設定項目へフォーカスを移動します（先頭の前は末尾へ循環）。 |
| `↑` / `↓` | **設定値の選択・変更** | セレクトボックスの選択肢を変更します（即時反映）。 |
| `Space` / `Enter` | **フォルダ参照の実行** | 「参照...」ボタン選択時にフォルダ選択ダイアログを開きます。 |
| `Esc` | **設定を閉じて復帰** | 設定画面を閉じ、エディタの直前のカーソル位置へ即座に復帰します。 |

## 📁 ファイル管理・その他
ホームフォルダの操作やアプリ全体の基本ショートカットです。

| ショートカットキー | 操作内容 | 備考 |
| :--- | :--- | :--- |
| `Ctrl` + `E` | **エクスプローラーを開く** | 保存先（ホームフォルダ）をOS標準のエクスプローラーで開きます。 |
| `F1` | **ショートカット一覧** | ショートカットヘルプ画面を別ウィンドウで表示します。 |
| `Ctrl` + `Q` | **アプリケーション終了** | 編集中の内容を安全に保存した上で、アプリを終了します。 |

## 🚫 無効化されているショートカット
誤操作によるデータ消失や、予期せぬ表示崩れを防ぐため、以下の一般的なブラウザショートカットは意図的に無効化されています。

| ショートカットキー | 元のブラウザ挙動 | 無効化の理由 |
| :--- | :--- | :--- |
| `Ctrl` + `R` | ページの再読み込み | 作業中の未保存データが予期せず失われるのを防ぐため。 |
| `Ctrl` + `P` | 印刷ダイアログの表示 | ブラウザの標準印刷画面がエディタの表示を崩してしまうため。 |
