# 複数ファイルオープンおよびシンタックスハイライト対応 ウォークスルー (Walkthrough)

## 1. 概要
NoCapEdit Ver 0.2.13 において、複数のファイルを開く機能（`Ctrl + O` によるファイル選択ダイアログ、およびドラッグ＆ドロップ）と、CodeMirror 6 の言語機能を用いたファイル拡張子に応じた自動シンタックスハイライト（構文強調表示）を実装しました。

---

## 2. 主な変更点と実装内容

### 2.1 CodeMirror 6 による自動シンタックスハイライト
- `@codemirror/language-data` パッケージを導入し、`@codemirror/language` の `syntaxHighlighting(defaultHighlightStyle, { fallback: true })` と連携。
- `languageCompartment` を新設し、ファイルの拡張子（Markdown, JavaScript, TypeScript, Python, Rust, JSON, YAML, TOML, HTML, CSS, C/C++, Java, Go, SQL, Shell など）を自動判定してオンデマンドでパーサー・言語ハイライトをロード＆適用。
- `.ncmd` は Markdown として解釈し、`.nctx` や `.txt`、未対応形式はプレーンテキストとして安全に表示・編集。
- 別名保存（`saveTabAs`）で拡張子が変更された場合も、動的に言語ハイライトが切り替わるよう対応。

### 2.2 複数ファイルの一括オープン機能
- **`Ctrl + O` ショートカット / ファイル選択ダイアログ**:
  - ダイアログ上で単一ファイルだけでなく、複数のファイル（`multiple: true`）を同時に選択して一括でタブに開くことが可能。
- **ドラッグ＆ドロップ (`tauri://file-drop`)**:
  - エクスプローラーからウィンドウへの複数ファイルドロップに対応し、ドロップされたすべてのファイルを順次タブとしてオープン。
- **初期空タブの自動置換**:
  - 起動直後の未編集・未作成の初期空タブ（ファイルパスなし・内容空）が存在する場合、最初のファイルを開いた際にその空タブを置換して開くことで、余分な空タブが残らないよう配慮。
- **同一ファイルの重複防止**:
  - 既にタブとして開かれているパスのファイルを再度開いた場合は、新規タブを作らずに既存タブへフォーカスを切り替え。

### 2.3 ショートカット・ヘルプ・i18n の更新
- `src/frontend/i18n.js` にファイルオープン関連の通知文言を追加。
- `src/frontend/help.html`（F1ヘルプ画面）および `docs/SHORTCUTS.md` に `Ctrl + O`（ファイルを開く）を追記。
