## 2. プロダクト概要 & コアコンセプト
NoCapEdit は、起動直後からすぐに書き始められ、ファイル名を考えずに保存できることを重視したシンプルなテキストエディタである。

一般的なテキストエディタでは、新規作成直後はまだ保存先やファイル名が決まっていないため、保存時に別途入力が必要になる。NoCapEdit ではこの手間をなくし、起動時点で保存先とファイル名を自動的に確定させることで、書くことに集中できる体験を提供する。

### コア体験
- アプリを起動した瞬間に、新規テキストファイルが自動生成されて開いている
- ユーザーはすぐに入力を開始できる
- 入力停止時、タブ切替時、タブ終了時、アプリ終了時に自動保存される
- 複数タブで新規ファイルを扱える
- 保存失敗時に、最低限のリカバリ操作ができる

## 3. 対象プラットフォームと技術方針
### 3.1 対象プラットフォーム
- 現在は Windows を対象とする。
- 将来的に macOS、Linux、CLI 版への展開を視野に入れる。

### 3.2 開発技術
- アプリケーション基盤: Tauri
- コア実装言語: Rust
- フロントエンドビルドツール: Vite (npm)
- エディタエンジン: CodeMirror (v6)
- UI方針: モダンで落ち着いた見た目を目指し、Obsidian や Zed のような雰囲気を参考にする。
- **内部設計について**: 多言語対応 (i18n)、設定定数管理、コードのモジュール構造に関する実装方針の詳細は、[ARCHITECTURE.md](ARCHITECTURE.md) を参照すること。

### 3.3 ウィンドウ表示制御（起動時チラつき防止）
- アプリ起動時の画面のガタつきやチラつき（Flash of Unstyled Content: FOUC）を防ぐため、内部的に起動時はウィンドウを非表示にし、フロントエンド側の描画が完全に整ったタイミングで表示させる制御を行う（詳細は [ARCHITECTURE.md](ARCHITECTURE.md) 参照）。

## 4. 機能仕様

### 4.1 初回起動とホームフォルダ
- **ホームフォルダ設定**:
  - 初回起動時にホームフォルダ設定画面を表示する。
  - デフォルトのホームフォルダは Windows の Documents 配下の nce フォルダとする。
    - 具体例: `C:/Users/<ユーザー名>/Documents/nce`
  - ユーザーはデフォルト値をそのまま採用することも、変更することもできる。
  - 設定したホームフォルダは `config.json` に永続化され、次回以降も自動的に使用される。
- **エクスプローラー連携**:
  - `Ctrl+E` ショートカットにより、設定されたホームフォルダをOS標準のエクスプローラーで即座に開くことができる。

### 4.2 起動時・新規作成時のファイル自動生成（遅延作成）
- **遅延ファイル作成**:
  - アプリ起動時および新規タブ作成時には、ディスク上にファイルの実体（0バイトのファイル）を作成しない。
  - ファイルの作成は、ユーザーが文字を入力して最初の自動保存（または手動保存）が実行されるまで遅延させる。
  - ファイル名形式は**初回保存が実行された時刻**のローカル時刻を基準とした `yyyymmdd_hhmmss.nctx` とする。
- **連番による衝突回避**:
  - 初回保存時に同名ファイルが既に存在する場合は、`_1`、`_2` のように1桁の連番を付けて回避する（最大9回＝1秒間に最大10ファイルまで生成可能。上限超過時はエラーで保存中断）。

### 4.3 タブ管理と複数ファイル操作
- **複数タブのサポート**:
  - 複数ファイルをタブで開け、タブの表示名は以下のルールに従ってフォーマットする：
    - **ファイル未作成（未保存）状態**: タブ作成順の連番を用いて、自動保存モードでは `未保存N`、手動保存モードでは `[未保存N]` と表示する（N はアプリ起動中のセッション内でインクリメントし、再起動でリセット。上限なし）。
    - **初回保存後（自動生成ファイル）**: ファイル名形式（`yyyymmdd_hhmmss.nctx` または連番付きの `yyyymmdd_hhmmss_x.nctx` / `yyyymmdd_hhmmss_xx.nctx`）に一致するファイルについては、`yyyy/mm/dd hh:mm:ss`（連番付きの場合は `yyyy/mm/dd hh:mm:ss-x`。例えば、`20260709_222843_1.nctx` は `2026/07/09 22:28:43-1` のようにインデックスを1始まりの整数値にしてハイフンで繋ぐ）として表示する。手動保存モードでは `[yyyy/mm/dd hh:mm:ss]`（連番付きは `[yyyy/mm/dd hh:mm:ss-1]`）のように角カッコで囲む。
    - **明示的な名前のファイル**: ユーザーが明示的に保存した、または外部から開いた自動生成規則に一致しないファイルについては、ファイル名と拡張子をそのまま表示する（例: `main.rs` は自動保存モードでは `main.rs`、手動保存モードでは `[main.rs]` と表示する。`memo.txt` も同様に `memo.txt` / `[memo.txt]` と表示する）。
- **タブ操作とUI**:
  - タブバーにあるプラス（`+`）ボタン、またはキーボードショートカット `Ctrl+T` から新規タブを開く。
  - キーボードショートカット `Ctrl+W` により、現在アクティブなタブを閉じる。最後の1つのタブを閉じた場合は自動的に新規空タブが作成される。
  - キーボードショートカット `Ctrl+Q` により、編集中の内容を安全に保存した上でアプリケーションを終了する。
  - プラス（`+`）ボタンはタブ領域のすぐ右側に配置され、タブの増加に合わせて右へ移動する。タブ領域が画面幅いっぱいに達した場合は、ボタン位置は右端で固定され、タブ領域のみが横スクロール可能となるUIを採用する。
    - タブのスクロールバーはテーマに合わせた落ち着いた薄い水色系で表示され、マウスホバー時には強調表示される。
    - タブ領域上にマウスカーソルがある際は、マウスホイールの上下回転によりタブ一覧を左右に水平スクロールできる。
  - 各タブは、ファイルパス、未保存フラグなどの内部状態を個別に保持する。
  - タブの切り替え時や新規作成時には、エディタに自動的にフォーカスが当たる。また、既存タブ間の切り替え時には、直前のカーソル位置（およびスクロール位置）がタブごとに保持され、切り替え後に復元される。
  - フォーカス中のタブを閉じた際は、直ぐ右隣のタブ（右隣がない場合は左隣のタブ）へ自動的にフォーカスが移動する。非フォーカス中のタブを閉じた場合はフォーカス位置は維持される。

### 4.4 テキスト編集機能
- **文字コード & 改行コード**:
  - 新規作成ファイルの文字コードは **UTF-8** とする。
  - 外部ファイル読み込み時は、BOM（UTF-8/UTF-16）およびバイト列解析により **UTF-8 / Shift_JIS (CP932) / EUC-JP / UTF-16** 等を自動判定してデコードする。
  - 既存ファイルの上書き保存時は、読み込み時に判定された文字コード（Shift_JIS 等）を維持してディスクへ安全に保存する。
  - 保存時の改行コードは Windows 向けとして **CRLF** に統一する。ファイル読み込み時は LF/CRLF を許容するが、保存時に正規化する。
- **行操作機能（移動・複製・削除）**:
  - 現在行（または選択中の複数行）の上下移動、直上/直下への行複製、行ごと一括削除に対応する。
  - 単一行のみならず複数行にわたる選択範囲（ブロック）にも完全対応し、操作後のカーソル位置・選択範囲を適切に追従させる。また、日本語入力の誤動作を防ぐため IME変換中はショートカットを抑制する。
  - 行操作やインデント操作（`Tab` / `Shift + Tab`）などのテキスト編集処理は、エディタエンジン（CodeMirror）のトランザクションとして実行されるため、Undo/Redo（`Ctrl+Z` / `Ctrl+Y`）に完全連動する。
  - ※各キーボードショートカット（`Alt+↑/↓` 等）の割り当て一覧は [SHORTCUTS.md](SHORTCUTS.md) を参照。
- **タイムスタンプ挿入 (`F5`)**:
  - `F5` キー押下時、カーソル位置に現在日時（`YYYY/MM/DD HH:mm` 形式、例: `2026/08/15 23:05`）を挿入する。範囲選択がある場合は選択範囲を日時テキストで置換する。
  - 挿入後はカーソルが日時の末尾に移動し、Undo/Redo に完全連動する（IME変換中は誤動作防止のため抑制）。
- **検索・置換機能 (`Ctrl + F` / `Ctrl + H`)**:
  - CodeMirror (v6) のエディタ基盤と連携し、エディタ右上にフロート表示されるコンパクトな2行レイアウトのカスタムウィジェットを採用する。
  - **1行目（検索段）**: `[検索入力欄  Aa]` （大文字/小文字区別ボタン内包）、`0 / 0` （マッチ件数・位置表示）、`▲` / `▼` （前後移動）、`✕` （閉じる）
  - **2行目（置換段）**: `[置換入力欄]`、`[置換]` ボタン、`[すべて置換]` ボタン
  - **動作仕様**: 次/前の一致箇所への移動、エディタ中央へのスムーズスクロール、エディタ選択単語の自動入力、全置換、Undo/Redo連動をサポート。
  - **多言語対応**: すべてのボタン・プレースホルダー・ツールチップおよび置換件数通知は `i18n.js` にて多言語管理（オブジェクトキーの重複・上書きのない単一構造で一元管理）。
  - ※検索パネル内のナビゲーションキーやショートカット一覧は [SHORTCUTS.md](SHORTCUTS.md) を参照。
- **指定行ジャンプ機能 (`Ctrl + G`)**:
  - エディタ右上にフロート表示される入力ウィジェットを採用し、検索・置換ウィジェットと排他的に表示を切り替える。
  - **入力解釈**:
    - **正の行番号**: 1行目から数えた行番号（例: `10` → 10行目へ移動）。
    - **負の行番号（行末からの逆算）**: 総行数を $N$ としたとき $N - |line| + 1$ 行目へ移動（例: `-1` は最終行、`-5` は行末から5行目）。
    - **列指定（コロン区切り）**: `行番号:列番号` の形式で行内の指定文字位置へ移動（例: `10:5`、`-5:1`）。列番号が範囲外の場合は行頭（1文字目）または行末に自動クランプ（丸め）する。
  - **バリデーションとリアルタイムエラー表示**:
    - 行番号が `0`、総行数超え、計算結果が0以下になるマイナス値、または数値以外の不正な文字が含まれる場合は、入力枠の境界線を赤く変化させ、入力欄下部にエラーメッセージを赤文字でリアルタイム表示する。エラー状態中は `Enter` キーによるジャンプを抑止する。
  - **キーボード操作 & スクロール**:
    - `Ctrl + G` で開閉（トグル）。ウィジェット展開時は直前の入力文字列を全選択し、即座に再入力可能とする。
    - `Enter` で指定位置へジャンプしてウィジェットを閉じ、エディタへフォーカスを復帰。
    - `Esc` または ✕ ボタンでキャンセルしてウィジェットを閉じ、元のカーソル位置を維持。
    - ジャンプ後の行はエディタ画面の中央（縦方向）にスクロール表示される。
  - **多言語対応**: プレースホルダー、エラー文、ツールチップを `i18n.js` にて多言語管理。
- **日本語IMEインライン入力およびマルチディスプレイ追従**:
  - CodeMirror 6 のエディタ基盤と連携し、日本語入力（IME）の未確定文字列および変換候補ウィンドウを常にキャレット（カーソル）直下にインライン表示する。
  - マルチディスプレイ環境においてウィンドウを別のディスプレイ領域へ移動させた際、ウィンドウ移動完了（移動停止から約150ms後）を検知して自動的にエディタのフォーカスおよびキャレット座標の再同期（リフレッシュ）を行い、移動直後から手元での正常なインライン入力を維持する（IME変換中の移動時は変換確定後に安全に遅延実行）。
- **テキスト選択表示および単語一致ハイライト**:
  - CodeMirror 6 の `drawSelection()` 拡張機能を用いて、選択中のテキスト範囲に行の高さ（`line-height`）に合わせた均一な背景色を描画する（ブラウザネイティブの `::selection` 重複描画を防止し、色ムラのない単一トーンで描画）。
  - エディタの左右パディング（16px）を行コンテナ（`.cm-line`）に適用することで、複数行選択時の中間行および終了行において、行頭左側の余白部分（行番号ガターと文字の間の領域）や右端余白に選択色がはみ出して塗られることを防止し、文字の描画開始位置から綺麗に選択ハイライトが揃う仕様とする。
  - エディタ内で単語を選択した際、同一文書内に存在する他の同一キーワードを黄色で自動的にハイライト表示する（`highlightSelectionMatches`）。

### 4.5 ファイル保存と安全保護
- **保存モード（設定で切り替え可能）**:
  - アプリ全体の設定として「自動保存モード」と「手動保存モード」を切り替えられる。設定変更は即座に反映され、開いている全タブに適用される。
  - **自動保存モード（デフォルト）**: 起動時や新規作成時にファイルを遅延作成し、入力停止時やタブ切替時に自動保存する。
  - **手動保存モード**:
    - 起動時や新規タブ作成時にファイルの実体を作成しない（遅延作成待ち）。
    - タブ名にはファイル名の代わりに `[未保存N]`（N は連番）を表示する。初回手動保存（`Ctrl+S`）後は `[yyyy/mm/dd hh:mm:ss]` に切り替える。
    - 入力停止時やタブ切替時の自動保存は行われない。
    - タブやウィンドウを閉じる際、未保存の変更があっても確認ダイアログは出さず、内容はすべて破棄される。
- **自動保存トリガー（自動保存モード時）**:
  - エディタ内のテキストが変更されたら未保存フラグを立てる。
  - 以下のタイミングで自動保存（未保存フラグがある場合のみ）を実行する。
    - ①入力停止から **3秒経過** 時（デバウンス処理）
    - ②タブ非アクティブ時（タブ切り替え時など）
    - ③タブを閉じる時
    - ④アプリ終了時
- **手動保存 (`Ctrl + S`)**:
  - `Ctrl + S` キー押下時、アクティブタブのテキスト内容を即座に保存する。自動保存の待機時間はキャンセルされる。
  - **手動保存モードでの初回保存**: ファイル未作成のタブ（`[未保存N]`）で `Ctrl + S` が押された際は、ホームフォルダに対してダイアログを出さずに `yyyymmdd_hhmmss.nctx` というファイル名を生成して新規ファイルを作成・保存する（保存後はタブ名が `[yyyy/mm/dd hh:mm:ss]` に変化する）。なお、ファイル未作成で内容が空（または空白文字のみ）の場合はファイル作成をスキップする。
  - **既存ファイルの上書き保存**: すでにファイルが作成されているタブ、または外部から開いたファイル（`memo.txt` 等）で `Ctrl + S` が押された際は、ファイル名やタイムスタンプを変更せず既存ファイルへ上書き保存する（既存ファイルの文字コードも維持される）。
- **名前をつけて保存 (`Ctrl + Shift + S`)**:
  - `Ctrl + Shift + S` キー押下時、Windows標準の「名前をつけて保存」ダイアログ（Common Item Dialog）を表示し、任意のファイル名・保存場所・拡張子でファイルを保存できる。ダイアログ内で新規フォルダを作成して保存することや、別ドライブへ保存することも可能。
  - **初期フォルダ・初期ファイル名**:
    - 新規（未保存）タブの場合: 設定されたホームフォルダ（例: `Documents/nce`）を初期フォルダとし、その時点の日時タイムスタンプ（`yyyymmdd_hhmmss.nctx`）をファイル名入力欄の初期値として設定する。
    - 既存ファイルタブの場合: 対象ファイルが存在する親フォルダを初期フォルダとし、現在のファイル名を初期値として設定する。
  - **ファイルの種類（拡張子フィルター）**:
    - `NoCapEdit Text (*.nctx)`（デフォルト）
    - `Text Files (*.txt)`
    - `CSV Files (*.csv)`
    - `すべてのファイル (*.*)`
  - **保存後の挙動**:
    - 元のファイルはそのままディスク上に保持（複製・別名保存）し、対象タブのファイルパスおよびファイル名を新しく保存したファイルへ切り替える。
    - タブの表示名を保存後のファイル名に更新し、未保存フラグ（`isDirty`）を解除する。
    - 新しいファイルの拡張子に応じたシンタックスハイライト（言語サポート）を自動適用する。
    - 以降の自動保存（自動保存モード時）または手動保存（`Ctrl + S`）は、新しく保存されたファイルに対して行われる。
- **自動クリーンアップ（空ファイル削除・未作成スキップ）**:
  - タブを閉じる時、またはアプリを終了する時、対象タブのファイル名が自動生成規則（`yyyymmdd_hhmmss.nctx`）に一致し、かつ**内容が空または空白文字のみ**で構成される場合は、以下の処理を行う：
    - すでにディスクにファイルが作成されている（`filePath` が存在する）場合：そのファイルをディスクから削除してタブを閉じる。
    - まだファイルが作成されていない（`filePath` が空の）場合：ディスク操作は行わず、そのままタブを閉じる。
  - **空白文字の定義**: 空文字、半角スペース、全角スペース（`\u3000`）、タブ、改行、およびそれらの組み合わせを空とみなす。
  - 上記の削除条件に当てはまらないタブについては、未保存フラグがある場合のみ保存を試行する。
- **安全保存方式**:
  - 保存時にファイル破損を防ぐため、一時ファイルに書き出してから置換する方式を採用する。これにより OneDrive 等のクラウド同期フォルダでの競合を防ぐ。
- **保存失敗時のリカバリ**:
  - 保存失敗時はステータスバーやダイアログでユーザーに通知する。
  - アプリ終了時の保存失敗では「再試行」「別名で保存」「終了を中止」の選択肢を提示する。

### 4.6 ファイルオープンと読み込み安全ガード
- **ファイルを開く (`Ctrl + O` / ドラッグ＆ドロップ / 右クリックメニュー)**:
  - `Ctrl + O` キー押下により、ファイル選択ダイアログを表示してファイルを開くことができる。単一ファイルだけでなく、**複数ファイルの一括選択・同時オープン**に対応する。
  - エクスプローラーからウィンドウへのファイル（単一または複数）の**ドラッグ＆ドロップ**による一括オープンに対応する。
  - **右クリックメニュー（「NoCapEdit で開く」）**:
    - Windowsのエクスプローラー上で任意のファイルを右クリックした際、コンテキストメニューに「NoCapEdit で開く」をアイコン付きで表示し、選択すると対象ファイルをNoCapEditで開くことができる。
    - 未起動時はファイルを開いた状態でアプリが起動し、既に起動中の場合は多重起動せず既存ウィンドウがアクティブになり新規タブとしてスマートに追加される。
    - インストーラー（NSIS）の追加オプション画面にて、右クリックメニュー登録の有効/無効を選択可能（デフォルト有効）。アンインストール時は登録されたレジストリを自動的に完全削除する。
  - **初期空タブの自動置換**:
    - 起動直後の「未保存・未編集の初期空タブ（ファイル未作成で内容が空）」が存在する場合、最初のファイルを開いた際にその空タブを置換して開き、余分な空タブを残さない。
  - **重複オープンの防止**:
    - 既にタブとして開かれている同一パスのファイルを開いた場合は、新規タブを作成せず対象タブへフォーカスを切り替える。
- **バイナリファイルおよび巨大ファイルの安全ガード**:
  - **ファイルサイズ上限ガード（10MB）**: 10MB（10,485,760 bytes）を超えるファイルは、アプリケーションのフリーズやクラッシュを防止するため読み込みをブロックし、ステータスバーに「ファイルサイズが上限（10MB）を超えているため開けません」と安全に通知する。
  - **バイナリ検出ガード（NULLバイトスキャン）**: 画像（.png, .jpg 等）や実行ファイル（.exe 等）などのバイナリデータ（先頭ブロックに NULL バイト `0x00` が含まれるファイル）は、エディタでの文字化け表示および自動保存による元ファイルの不可逆な上書き破壊を防止するため読み込みをブロックし、「バイナリファイルのため開けません」と安全に通知する。
- **シンタックスハイライト（構文強調表示）**:
  - 任意のテキストファイル形式（All Files `*.*`）を開くことができる。
  - CodeMirror 6 の言語サポート定義に基づき、開いたファイルの拡張子（Markdown, JavaScript, TypeScript, Python, Rust, JSON, YAML, TOML, HTML, CSS, C/C++, Java, Go, SQL, Shell 等）に応じたシンタックスハイライトを自動適用する。
  - 対応言語定義のない拡張子やプレーンテキスト（`.txt`, `.nctx` など）はプレーンテキストモードとして安全に表示・編集する。

### 4.7 画面表示（タイトルバー・ステータスバー・エディタ情報）
- **タイトルバーバージョン表示**:
  - ウィンドウタイトルに `NoCapEdit [ Ver X.Y.Z ]` を表示する。
  - バージョン番号は `Cargo.toml` の `version` を一元的なマスター（Source of Truth）とし、バックエンド経由でフロントエンド（`document.title`）に動的に反映する。
- **保存状態のステータス表示**:
  - 画面下部のステータスバーに、保存状態を表示する。
  - **新規作成・初期状態のステータス表示**:
    - アプリ起動時および新規タブ作成時（ファイル未作成の遅延保存待ち状態）は、現在の保存モードに応じて以下の初期ステータスを表示する：
      - **自動保存モード時**: `保存準備完了`
      - **手動保存モード時**: `[手動保存モード] ※Ctrl+Sで保存できます`
    - ユーザーが文字を入力し、最初の自動保存または手動保存が実行されて実際にディスク上にファイルが作成された時点で、初めて `[ファイル名] を作成` と表示する。
  - **編集・保存・開いた時・タブ切り替え時のステータス表示**:
    - ファイルの実体が存在する場合（既存ファイルを開いた後、または新規ファイルが初回保存された後）は、ステータスバーに `[接頭辞][ファイル名] ([文字コード]) - [状態]` の形式で表示する。
      - `[接頭辞]` : 自動保存モード時はなし。手動保存モード時は `[手動保存:Ctrl+S] ` とする。
      - `[文字コード]` : ファイルのエンコーディング（例: `UTF-8`, `Shift_JIS`, `EUC-JP` 等）。
      - `[状態]` : `編集中` / `保存中...` / `保存済み` / `保存失敗` 等。
      - 例（自動保存）: `sales.csv (Shift_JIS) - 保存済み`、`main.rs (UTF-8) - 編集中`
      - 例（手動保存）: `[手動保存:Ctrl+S] sales.csv (Shift_JIS) - 保存済み`
    - ファイルを開いた直後のみ、状態表示の代わりに `[ファイル名] ([文字コード]) を開きました` と表示する（手動保存モード時は `[手動保存モード] [ファイル名] ([文字コード]) を開きました`）。
    - 初回保存が完了した瞬間のみ、状態表示の代わりに `[ファイル名] を作成` と表示する（手動保存モード時は `[手動保存:Ctrl+S] [ファイル名] を作成`）。
    - 他のタブへ切り替えた際は、そのタブの現在の状態を自動判別し、ステータス表示を正確に復元する。
  - ユーザーの集中を妨げないため、ポップアップ通知は表示せず、ステータスバーのテキスト更新のみで静かに通知する。
- **エディタ情報表示**:
  - ステータスバーの右側には、現在のカーソル位置、文字数、フォントサイズ、行間高さを表示する。
  - 文字数のカウントは、設定された「文字数カウント方法」に基づいて計算される。
  - 表示形式:
    - 範囲選択をしていない場合: `Ln X, Col Y | Z chars | Font xx pt | LH x xx` （Zは文字数）
    - 範囲選択をしている場合: `Ln X, Col Y | S / Z chars | Font xx pt | LH x xx` （Sは選択範囲の文字数、Zは全体文字数）

### 4.8 ファイル関連付け・専用アイコン・シングルインスタンス
- **ファイル保存と拡張子**:
  - ファイル保存（別名保存）ダイアログでは、デフォルトを `.nctx` (NoCap Text) としつつ、`.txt`（一般テキスト）、`.ncmd`（Markdown）も選択可能とする。
- **ファイル専用アイコン (`document.ico`) とアプリアイコンの分離**:
  - **アプリアイコン**: `NoCapEdit.exe` 本体、デスクトップショートカット、スタートメニュー、タスクバー等では丸いアプリアイコン（赤丸＋帽子＋青E）を使用する。
  - **ファイル専用アイコン**: NoCapEdit に関連付けられたファイル（`.txt`, `.nctx`, `.csv`, `.py` 等）には、専用のドキュメントアイコンを表示する。デスクトップ等での大アイコン表示用デザインと、エクスプローラー詳細表示等での高視認性デザイン（WPSスタイル）を統合したマルチサイズ ICO を採用する（詳細は [ARCHITECTURE.md](ARCHITECTURE.md) 参照）。
- **OSファイル関連付けとレジストリ登録**:
  - NSISインストーラーにより、主要なテキスト・コード系拡張子に対する共通 ProgID（`NoCapEdit.Document`）の関連付けおよび推奨アプリ登録を行い、関連付けされたファイルに専用アイコンを自動適用する。
  - アンインストール時は関連付け情報およびアイコンファイルを完全に削除する。
- **単一ウィンドウ動作（シングルインスタンス）**:
  - アプリは常に単一のメインウィンドウでのみ動作する（多重起動の防止）。
  - すでにアプリが起動している状態で、エクスプローラーでのダブルクリック等により別プロセスが起動された場合、新規プロセスは起動引数のファイルパスを既存ウィンドウに通知して終了する。
  - 既存ウィンドウは通知されたファイルパスを新規タブとして開きアクティブ化し、ウィンドウを最前面に復元する。

### 4.9 ユーザー設定と永続化
ユーザー設定は設定ファイル（`config.json`）に保存され、次回起動時も自動的に適用される。

- **設定画面のUI（右ドック形式）**:
  - 設定画面は画面右側からスライドインするドック形式で表示される。
  - 設定ボタン（歯車アイコン）のクリック、またはショートカットキー `Ctrl + ,`（カンマ）で開閉（トグル）でき、開いている間は設定ボタンが「✕（閉じる）」アイコンに変化する。
  - 項目が増加した場合でも、ドック内のみで縦スクロールが可能。
  - 各設定項目は、変更された瞬間に即座に反映され、自動的に保存処理が行われる（OKボタンは不要）。
  - 設定画面を閉じた際、エディタに自動的にフォーカスが戻り、開く直前のカーソル位置（およびスクロール位置）が復元される。
  - **キーボード完全操作（アクセシビリティ）**:
    - `Ctrl + ,` で開いた際、最上部の「参照...」ボタンに初期フォーカスが当たる。
    - `Tab` / `Shift + Tab` で設定項目間を順次移動でき、末尾から先頭へループする（フォーカストラップ）。
    - 各セレクトボックスは方向キー `↑` / `↓` または `Enter` / `Space` で選択肢を変更・確定できる。
    - `Esc` または `Ctrl + ,` で設定ドックを閉じ、エディタの元のカーソル位置へ即座に復帰できる。設定開閉・変更後もテキストの Undo/Redo は保持される。
    - **常時固定フッター（操作ヒント）**: 設定ドックの最下部に「💡 Tab: 項目移動 │ ↑↓: 選択 │ Space: 実行 │ Esc: 閉じる」のヒントを常時固定表示する。
- **テーマ切り替え**:
  - 以下の3つのカラーモードをサポートし、設定ドック内のドロップダウンで切り替える。
    - **Dark**（内部キー: `dark`）: 完全な黒ベースのダークモード
    - **Soft Dark**（内部キー: `soft-dark`）: グレーベースの柔らかいダークモード（Zed風）
    - **Light**（内部キー: `light`）: 白ベースのライトモード
  - DWM APIを利用し、DarkおよびSoft DarkモードではWindowsのウィンドウタイトルバーをダーク色に同期させる。LightモードではOS標準のライト色にする。
- **フォントサイズ設定 & ズーム調整**:
  - **設定画面での永続化**: 設定ドックの「フォントサイズ」セレクトボックスから選択でき（8pt〜72pt、デフォルト 20pt）、`config.json` に保存される。
  - **ショートカットでの一時調整**: キーボード・マウス操作により 1pt 刻みで一時的に拡大・縮小できる（一時変更は設定ファイルへ保存されない。キー操作詳細は [SHORTCUTS.md](SHORTCUTS.md) 参照）。
- **行間設定 & 調整**:
  - **設定画面での永続化**: 設定ドックの「行間」セレクトボックスから選択でき（1.0〜3.0、デフォルト 1.5）、`config.json` に保存される。
  - **ショートカットでの一時調整**: キーボード・マウス操作により 0.1 刻みで一時的に変更できる（一時変更は設定ファイルへ保存されない。キー操作詳細は [SHORTCUTS.md](SHORTCUTS.md) 参照）。
- **ズーム・行間のリセット (`Ctrl + 0`)**:
  - ショートカットキー（`Ctrl + 0`）により、一時変更されたフォントサイズと行間を設定画面の永続設定値に即座に復元する（Undo/Redo 履歴は保持。詳細は [SHORTCUTS.md](SHORTCUTS.md) 参照）。
- **行の折り返し (Word Wrap)**:
  - **設定画面での永続化**: 設定ドックの「行の折り返し」セレクトボックスから「有効（折り返す / デフォルト）」または「無効（折り返さない）」を選択でき、`config.json` に保存される。
  - **ショートカット (`Alt + Z`) での一時切り替え**: 作業中のアクティブタブに対してのみ即座に折り返しの ON/OFF をトグルする。他のタブや基本設定には影響せず、タブ個別状態で保持される（詳細は [SHORTCUTS.md](SHORTCUTS.md) 参照）。
  - **表示スタイル**:
    - 有効（ON）: ウィンドウ幅に合わせて行末で自動折り返し（横スクロールなし）。
    - 無効（OFF）: 折り返さずに横に伸び、画面下部に横スクロールバーを表示。
- **行番号の表示 (Line Numbers)**:
  - **設定画面での永続化**: 設定ドックの「行番号の表示」セレクトボックスから「無効（表示しない / デフォルト）」または「有効（表示する）」を選択でき、`config.json` に保存される。
  - **ショートカット (`Alt + L`) での一時切り替え**: 作業中のアクティブタブに対してのみ即座に行番号の表示/非表示（ON/OFF）をトグルする。他のタブや基本設定には影響せず、タブ個別状態で保持される（詳細は [SHORTCUTS.md](SHORTCUTS.md) 参照）。
  - **表示仕様**:
    - CodeMirror 6 のガター（`lineNumbers`）を利用し、テーマに合わせた配色スタイルでエディタ左端に行番号を表示する。
    - **余白制御**: 行番号表示時は境界線との余白を無し（`0px`）として境界線の直後からテキストを開始する。行番号非表示時は従来どおりエディタ左端に `16px` の余白を維持する。
    - 行折り返し時は物理行の先頭にのみ番号を表示し、折り返し行には表示しない。
    - ズーム（フォントサイズ）や行間変更時も本文行に完全追従する。
- **ルーラーの表示と縦ガイド線 (Ruler & Vertical Guide Lines)**:
  - **設定画面での永続化**: 設定ドックの「ルーラーの表示」セレクトボックスから「無効（表示しない / デフォルト）」または「有効（表示する）」を選択でき、`config.json` に保存される。
  - **ショートカット (`Alt + R`) での一時切り替え**: 作業中のアクティブタブに対してのみ即座にルーラーの表示/非表示（ON/OFF）をトグルする。他のタブや基本設定には影響せず、タブ個別状態で保持される（詳細は [SHORTCUTS.md](SHORTCUTS.md) 参照）。
  - **表示仕様**:
    - エディタ本文上部に等幅フォント文字幅基準の水平ルーラーを配置する。
    - 目盛りは短（1文字）、中（5文字）、長（10文字）の3段階で表示し、10文字単位で桁数（`10`, `20`, `30`, ...）を表示する。
    - 行番号ガター幅およびエディタパディングに合わせてルーラー開始位置（0桁目）が自動同期する。特に行番号表示時は、行番号境界線（ガター右端の縦線）とルーラーのスペーサー境界線および0桁目目盛りが一直線に揃う。
    - エディタ内のキャレット移動に追従し、ルーラー内側最下端に半角1文字幅・高さ1pxの赤いインジケーター（アンダーライン）を表示する。
  - **マーカーと縦ガイド線**:
    - ルーラー上をクリックすることで、任意桁位置に「▼」マーカーおよびエディタ本文への縦破線ガイド（`1px dashed`）を設置できる（最大10個まで）。
    - ルーラー上の既存マーカーをドラッグして左右の別の文字桁位置へ移動できる（文字境界目盛りにスナップ）。ドラッグせずにその場でクリックした場合は削除される。
    - エディタ本文内の縦ガイド線はテキスト選択・編集を阻害しないようクリックイベントが無効化（`pointer-events: none`）される。
    - マーカー位置はタブごとに独立して保持され、ルーラー非表示時はマーカーおよび縦ガイド線も連動して非表示となる。
    - 横スクロール時およびウィンドウリサイズ・フォントサイズ変更時も目盛りおよびガイド線の位置が完全連動する。
- **フォントファミリー選択 (遅延ロード・読み込み中表示搭載)**:
  - エディタのフォントファミリーを等幅（Monospace）とその他に分類してセレクトボックスから選択できる。
  - 起動時にはシステムフォントの全検出を行わず、設定済みの適用中フォントのみを表示して起動を高速化する。セレクトボックスをフォーカスした際に非同期でシステムフォントの検出を開始する。
- **インデント設定 & タブ入力制御**:
  - エディタ上で `Tab` キーを押下した際、他のフォーカス移動を行わず、インデント文字を挿入する。
  - 設定画面から「タブ文字 (4文字幅)」「タブ文字 (2文字幅)」「スペース 4文字」「スペース 2文字」の挙動を選択できる（※過去バージョンで保存された `"tab"` は「タブ文字 (4文字幅)」として互換性を維持）。
  - タブ文字の表示幅（CodeMirrorの `tabSize`）は設定された幅（2文字幅または4文字幅）に従って適切にレンダリングされる。
  - 複数行選択した状態で `Tab` / `Shift + Tab` を押下した際、選択範囲の各行頭に対して一括でインデント追加・削除を行う。
- **インデントガイドの表示 (Indent Guides)**:
  - **設定画面での永続化**: 設定ドックの「インデントガイドの表示」セレクトボックスから「無効（表示しない / デフォルト）」または「有効（表示する）」を選択でき、`config.json` に保存される。
  - **ショートカット (`Alt + I`) での一時切り替え**: 作業中のアクティブタブに対してのみ即座にインデントガイドの表示/非表示（ON/OFF）をトグルする。他のタブや基本設定には影響せず、タブ個別状態で保持される（詳細は [SHORTCUTS.md](SHORTCUTS.md) 参照）。設定ドックで他の設定（タブ幅やフォントサイズ等）を変更・保存した際にも、この一時切り替え状態は維持される（設定ドックでインデントガイド設定自体が明示的に変更された場合のみ反映）。
  - **表示仕様**:
    - 設定されたタブ幅（2文字/4文字）およびスペースインデント（2文字/4文字）に完全連動し、各インデント階層に薄い縦の実線（`1px solid`）を描画する。
    - 空白行（改行のみ、またはスペース・タブのみの行）でも、前後の非空行のインデント深さからブロック構造（VS Code準拠ロジック）を判定して補間描画する。
      - ブロック開始直後の空行（上の行より下の行のインデントが深い場合）: 直前行の深さ + 1 のガイドラインを表示し、上端の途切れを防ぐ。
      - ブロック終了直前の空行（上の行より下の行のインデントが浅い場合）: 直後行の深さ + 1 のガイドラインを表示し、下端の途切れを防ぐ。
      - 同一ブロック内の空行（上下の深さが同じ場合）: そのインデント深さを維持して表示する。
      - ファイル先頭や末尾の空行: ガイドラインは非表示とする。
    - 各カラーテーマ（Dark / Soft Dark / Light）に合わせて文字の可読性を損なわない薄い半透明カラーが適用される。
    - テキスト選択やキャレット移動を阻害しないようクリックイベントは無効化（`pointer-events: none`）される。
    - フォントサイズ変更（ズーム）や行間変更時も正確に追従する。
- **不可視文字の表示 (Invisible Characters)**:
  - **設定画面での永続化**: 設定ドックの「不可視文字の表示」セレクトボックスから「無効（表示しない / デフォルト）」または「有効（表示する）」を選択でき、`config.json` に保存される。
  - **ショートカット (`Alt + W`) での一時切り替え**: 作業中のアクティブタブに対してのみ即座に不可視文字の表示/非表示（ON/OFF）をトグルする。他のタブや基本設定には影響せず、タブ個別状態で保持される（詳細は [SHORTCUTS.md](SHORTCUTS.md) 参照）。設定ドックで他の設定を変更・保存した際にも一時切り替え状態は維持される。
  - **表示仕様**:
    - **半角スペース (` `)**: 等幅フォントの1文字幅を維持したまま、文字の中央に薄いグレーの丸ドット（`radial-gradient`）を表示する。
    - **全角スペース (`\u3000`)**: 全角1文字分の幅を維持したまま、文字の中央に薄いグレーの四角記号（`□`）を表示する（CSS疑似要素 `::before`）。
    - **タブ文字 (`\t`)**: 設定されたタブ幅（2文字幅または4文字幅）の右端に薄いグレーの右矢印（`→`）を表示する（CSS疑似要素 `::before`）。
    - **改行マーク (`\n`)**: 各行末に薄いグレーのリターン記号（`↵` / 下向き左折れ矢印）をWidgetとして表示する。ドキュメントの最終行（ファイル末尾で改行が存在しない行）には表示しない。
    - **テーマ連動カラー**: 各カラーテーマ（Dark / Soft Dark / Light）に合わせて文字の可読性を損なわない薄い半透明カラー（`--invisible-char-color`）が自動適用される。
    - **操作性の保護**: テキスト選択、コピー＆ペースト、キャレット移動、キーボード入力（IME入力含む）を一切阻害しない設計とする。
- **文字数カウント設定**:
  - 設定画面から、文字数のカウント方法を「改行を含む（デフォルト）」または「文字数のみ（改行を除く）」から選択できる。

### 4.10 自動アップデートチェック機能
- **バックグラウンドチェック**:
  - アプリ起動直後のUI描画を妨げないよう、数秒の遅延（約3秒）を挟んでからバックグラウンドで最新バージョン情報の取得を行う。
  - GitHub APIのReleasesエンドポイントを利用し、ドラフト・プレリリースを除外した最新の正式リリースを取得してバージョン比較（`compareVersions`）を行う。
  - ネットワークエラー等の失敗時は、エラー通知を行わず静かに処理を終了する。
- **通知UIの表示**:
  - 新しいバージョンが存在する場合、以下の2箇所に控えめな通知を表示する。
  1. **タイトルバー**: ウィンドウタイトルに `NoCapEdit [ Ver X.Y.Z ] (Update: vA.B.C)` の形式で追記する。
  2. **設定画面の最上段**: 設定画面（右ドック）内の最上部に、アップデート可能な旨（`アップデート可能です Ver. X.Y.Z → Ver. A.B.C`）とリリースノートへのリンクを表示する。リンククリック時は標準ブラウザで安全に外部ページを開く。

### 4.11 キーボードショートカット・ヘルプ・メニュー制限
- **ヘルプ機能（ショートカット一覧表示）**:
  - `F1` キー押下により、独立した別ウィンドウで「ショートカット一覧（ヘルプ画面）」を表示する。ウィンドウタイトルやカテゴリ・項目名等の文言は `i18n.js` により多言語管理される。
  - メイン画面のテーマ設定（Dark / Soft Dark / Light）とリアルタイムに同期し、`Esc` キーで閉じることができる。
  - ※利用可能な全ショートカットの一覧表は [SHORTCUTS.md](SHORTCUTS.md) を参照。
- **不要なブラウザ機能・ショートカットの無効化**:
  - デスクトップアプリとしての操作性や安全性を確保するため、不要なブラウザ標準機能（ページの再読み込み/リロード、印刷機能）を無効化する（無効化キーの一覧と理由は [SHORTCUTS.md](SHORTCUTS.md) 参照）。
  - ※単体の `F5` キーはエディタ内で「現在日時挿入」として動作するため、リロードは発生しない。
- **ブラウザ標準コンテキストメニューの制限**:
  - リリースビルドにおいてWebブラウザ標準の右クリックコンテキストメニュー（再読み込み、印刷、ソース表示など）を無効化する。
  - デバッグビルド（`cargo tauri dev` 等の開発環境）においてはコンテキストメニューを有効のまま維持する。
