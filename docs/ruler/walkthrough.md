# ウォークスルー: ルーラー表示および縦ガイド線機能 (Ver 0.2.25)

## 1. 概要
テキストの文字桁位置（カラム数）を視覚的に把握できる水平ルーラー（目盛りバー）の表示、およびルーラー上のクリックによる「▼」マーカー設置とエディタ本文領域への縦破線（Dashed）ガイド線表示機能を実装しました。

「行の折り返し（Word Wrap）」「行番号（Line Numbers）」と同様に、「設定ドックでのデフォルト値管理（永続化）」と「ショートカット（`Alt + R`）によるタブ個別のトグル切替」の2層設計を踏襲しています。

---

## 2. 実装された機能詳細

### 2.1 水平ルーラー表示
- **配置**: エディタ本文（`.editor-container`）の最上部に配置。
- **目盛りの刻み**:
  - 短目盛り: 1文字刻み
  - 中目盛り: 5文字刻み
  - 長目盛り: 10文字刻み（目盛りの上に `10`, `20`, `30`, ... と桁数テキストを表示）
- **文字幅の動的追従**:
  - 等幅フォント（`--editor-font-family`）の文字幅（`EditorView.defaultCharacterWidth` または '0' の計測幅）を正確に取得し、各目盛りおよび数字を配置。
- **ガター幅・本文パディングの同期**:
  - エディタ本文（`.cm-content`）の画面左端座標を直接実測し、行番号ガターの真上をスペーサー（`#rulerGutterSpacer`）で覆い、ルーラーの0桁目（開始位置）を本文の先頭文字の左端と完全に一致。
  - `ResizeObserver` による監視を導入し、行番号切り替えや設定ドック開閉時も自動追従。

### 2.2 カーソル追従インジケーター（全角・タブ対応）
- CodeMirror の画面座標取得 API（`coordsAtPos`）を採用。
- 全角文字（漢字・ひらがな・全角記号）やタブ文字が混在していても、画面上の実際のキャレットの真上に1ピクセルの狂いもなくインジケーター（赤線）が完全追従。

### 2.3 マーカー（▼）と縦破線ガイド線
- **マーカー設置**:
  - ルーラー上の任意桁をクリックすると、その桁位置に「▼」マーカーを設置し、エディタ本文領域に縦破線（`1px dashed var(--ruler-guide)`）を表示。
  - 1タブあたり最大10個まで設置可能（上限到達時は安全に無視）。
- **マーカー垂直配置**:
  - ルーラー上部の桁数数字（`10`, `20`...）との重なりを防ぐため、最小目盛り（短棒）の真上に「▼」マーカーを配置（`bottom: 5px`）。
- **ドラッグによる左右移動**:
  - ルーラー上の「▼」マーカーを左右にドラッグして、別の文字桁位置へ自由にスライド・移動可能。
  - ホバー時は `cursor: grab`、ドラッグ中は `cursor: grabbing` に変化。
  - ドラッグ中は文字境界の目盛り位置にリアルタイムにスナップ追従し、エディタ本文の縦破線も連動して移動。
  - ドロップした桁位置に固定され、タブのマーカー情報が自動更新。
- **クリックによる削除**:
  - マーカーをドラッグせずにその場でクリックした場合は、当該マーカーおよび縦ガイド線を削除。
- **マーカーとガイド線の水平位置完全一致**:
  - ルーラー上のマーカーの画面X座標とエディタ本文の縦破線の画面X座標を完全同期させ、マーカー先端から寸分違わず垂直に破線が伸びるよう描画。
- **エディタ操作の保護**:
  - 縦ガイド線は `pointer-events: none` となっており、エディタ本文側のガイド線上をクリック・ドラッグしてもテキストの選択・編集操作を一切阻害しません。

### 2.4 タブ個別状態管理と連動
- **スコープ**: タブごとに独立してルーラー表示状態（`tab.ruler`）およびマーカー桁一覧（`tab.rulerMarkers`）を保持。
- **連動動作**:
  - ルーラーがOFFの時はマーカーおよび縦ガイド線も連動して非表示。
  - タブを切り替えた際、各タブのルーラー表示状態およびマーカーが正確に復元。
- **横スクロール連動**:
  - 折り返し無効（`Alt + W`）で横スクロールが発生した際、エディタのスクロール（`scrollLeft`）とルーラー目盛りおよび縦ガイド線の水平位置が完全連動。
- **ズーム連動**:
  - フォントサイズ変更時（Ctrl+ホイール / キー）に文字幅を再取得し、目盛り間隔・マーカー位置・ガイド線位置を即座に再計算。

### 2.5 設定ドックとショートカット
- **設定ドック**:
  - 「ルーラーの表示（Ruler）」セレクトボックス（無効 [デフォルト] / 有効）を追加。設定ファイル（`config.json`）に永続化。
  - 新規作成タブのデフォルト表示状態として反映。
- **ショートカット**:
  - `Alt + R`: 作業中アクティブタブのルーラー表示/非表示（ON/OFF）をトグル。
- **ヘルプ画面**:
  - `F1` ヘルプ画面の「表示」カテゴリに `Alt + R`: ルーラーの表示切替 を追記。
