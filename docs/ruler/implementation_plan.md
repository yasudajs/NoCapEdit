# 実装計画書: ルーラー表示および縦ガイド線機能 (Ver 0.2.25)

## 1. 概要
エディタ上部に桁数（文字位置）を視覚的に把握できる水平ルーラー（目盛りバー）を表示し、ルーラー上のクリック操作により指定桁位置に「▼」マーカーおよびエディタ本文領域への縦ガイド線（破線）を表示する機能を追加する。

先行して実装された「行の折り返し（Word Wrap）」「行番号（Line Numbers）」と同様に、「設定ドックでのデフォルト設定（永続化）」と「ショートカットキーによるタブ個別のトグル切替」の2層構造を踏襲する。

---

## 2. 仕様詳細

### 2.1 ショートカットキー
- **`Alt + R`**: 現在アクティブなタブのルーラー表示/非表示をトグル切り替え。

### 2.2 設定管理
- **設定画面（設定ドック）**:
  - 項目名: 「ルーラーの表示（Ruler）」
  - 選択肢:
    - `無効（表示しない）`（デフォルト / `false`）
    - `有効（表示する）`（`true`）
  - 保存先: `settings.json` の `ruler` キーとして永続化。
  - 新規タブ作成時、設定ドックのデフォルト値が初期値として適用される。

### 2.3 ルーラーの表示仕様
- **配置**: エディタ本文（`.editor-container`）の上部に配置。
- **目盛りの刻み**:
  - 短目盛り: 1文字刻み
  - 中目盛り: 5文字刻み
  - 長目盛り: 10文字刻み（上部に `10`, `20`, `30`, ... と桁数を表示）
- **文字幅の算出**:
  - 等幅フォント（`--editor-font-family`）における半角1文字の幅（`EditorView.defaultCharacterWidth` または計測値）を基準として目盛りを配置。
- **左オフセット同期**:
  - 行番号ガター（`.cm-gutters`）の有無および幅、エディタ本文パディング（`.cm-content` の左パディング）に合わせてルーラーの開始位置（0桁目）を精密に同期。
- **カーソル追従インジケーター**:
  - エディタ内のキャレット移動に連動し、ルーラー上に現在の桁位置を示すインジケーターを表示。

### 2.4 マーカー＆縦ガイド線仕様
- **マーカーの追加**:
  - ルーラー上の任意位置をクリックすると、最も近い文字桁位置に「▼」マーカーを設置。
  - エディタ本文の該当桁位置に縦破線（Dashed: `1px dashed rgba(...)`）のガイド線を表示。
  - 設置上限: 1タブにつき**最大10個**まで。上限到達時はそれ以上の追加を無視。
- **マーカーの削除**:
  - ルーラー上の既存マーカーをクリックすると、そのマーカーおよび縦ガイド線を削除。
- **エディタ操作の保護**:
  - 縦ガイド線は `pointer-events: none` とし、エディタ本文側のガイド線上をクリック・ドラッグしてもテキストの選択・編集操作を一切阻害しない。
  - ガイド線の削除・トグル操作はルーラー上のマーカークリック時のみ有効。

### 2.5 タブごとの状態管理・連動
- **スコープ**: タブごとに独立して保持（`tab.ruler`: boolean, `tab.rulerMarkers`: number[]）。
- **ルーラー非表示時の挙動**:
  - ルーラーがOFFの時は、マーカーおよび縦ガイド線も連動して非表示となる。
  - ルーラー非表示時はマーカーの新規追加・操作は不可。
- **タブ切り替え時の復元**:
  - タブ切り替え時に、当該タブのルーラー表示状態および設置済みマーカー・縦ガイド線を復元。

### 2.6 スクロール・リサイズ・ズーム連動
- **横スクロール連動**:
  - 行の折り返しが無効で横スクロールが発生している場合、CodeMirrorのスクロール（`scrollDOM.scrollLeft`）にルーラーの目盛りおよび縦ガイド線が完全に同期して水平スライド。
- **リサイズ・ズーム連動**:
  - フォントサイズ変更（Ctrl+Plus/Minus/Wheel）、行番号ON/OFF切り替え、ウィンドウリサイズ時に文字幅・ガター幅を再取得して目盛りとガイド線の位置を再計算。

### 2.7 多言語対応（i18n）＆ヘルプ画面
- `src/frontend/i18n.js` に日英翻訳キーを追加。
- `src/frontend/help.html` の「表示」カテゴリに `Alt + R`: ルーラーの表示切替 を追記。

- [ ] `Alt + R` を押すと、アクティブタブにルーラーが表示されること（再度押すと非表示）。
- [ ] ルーラー上に 1文字・5文字・10文字 の目盛りおよび 10, 20, 30... の数字が正しく並ぶこと。
- [ ] カーソルを移動したとき、ルーラー上のインジケーターが現在の文字桁位置にスムーズに追従すること。
- [ ] ルーラー上をクリックすると、その桁に「▼」マーカーが設置され、エディタ本文領域に縦の破線ガイドが表示されること。
- [ ] マーカーが最大10個まで追加でき、11個目以降は追加されないこと。
- [ ] ルーラー上の既存マーカーをクリックすると、当該マーカーと縦ガイド線が削除されること。
