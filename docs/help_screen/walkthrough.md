# ヘルプ画面機能実装 ウォークスルー

## 概要
F1キーでショートカット一覧を確認できるヘルプ機能を追加しました。
「メニューを持たないシンプルなエディタ」というNoCapEditのコンセプトに合わせ、メイン画面のUIやレイアウトに干渉しない「別ウィンドウ方式」を採用しています。

## 変更内容
1. **設定と権限の追加**
   - `tauri.conf.json` の `allowlist.window` に `"create"`, `"close"`, `"setFocus"` を追加し、フロントエンドからのウィンドウ操作を許可しました。
   - `Cargo.toml` の `tauri` features にも上記の権限を追記しました。
2. **多言語対応 (i18n)**
   - `src/dist/i18n.js` に `help` セクションを追加し、ヘルプ画面で表示する各カテゴリとショートカット名の日本語テキストを定義しました。
3. **フロントエンドの実装**
   - **`src/dist/js/ui/shortcuts.js`**: `keydown` イベントに `F1` キーのフックを追加し、Tauriの `WebviewWindow` を用いて別ウィンドウを生成する処理を実装しました。すでに開いている場合はフォーカスを当てる処理も行っています。
   - **`src/dist/help.html`**: メイン画面とデザインを統一した、シンプルなショートカット一覧画面のマークアップを追加しました。テキストはすべて `data-i18n` 属性による置換を前提としています。
   - **`src/dist/js/help.js`**: ヘルプ画面読み込み時に `i18n.js` を呼び出して翻訳テキストを適用し、`Esc` キー押下時にウィンドウを閉じる処理を実装しました。
4. **仕様書の更新**
   - `docs/spec.md` に「4.11 ヘルプ機能（ショートカット一覧表示）」の仕様を追記しました。

## 確認事項
- `cargo build` が正常に通ることを確認しました。
- 実機での動作確認（`F1` キーでウィンドウが開き、`Esc` で閉じること等）は、必要に応じてユーザー環境にてお願いします。
