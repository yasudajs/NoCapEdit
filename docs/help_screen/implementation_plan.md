# ヘルプ機能（ショートカット一覧）の実装計画

## 背景・目的
NoCapEditはメニューを持たないシンプルなテキストエディタであり、操作は主にショートカットキーで行います。
ユーザーが操作方法を簡単に確認できるよう、`F1` キーで「ショートカット一覧」を表示するヘルプ画面を実装します。

## 設計方針・合意事項
- **表示形式**: 別ウィンドウとして表示する（Obsidianのヘルプのようなスタイル）。
- **フォーカス挙動**: ヘルプ画面を開いた際、フォーカスはヘルプウィンドウに移ってよい。エディタに戻る場合はユーザーが手動でフォーカスを戻す。
- **閉じる操作**: ヘルプウィンドウ上で `Esc` キーを押すとウィンドウが閉じる仕様とする。
- **テキストの多言語化**: プロジェクトルールに従い、ヘルプ画面の表示テキストは `src/dist/i18n.js` を用いて多言語対応（日本語・英語など）を行う。

## 追加・修正するファイル

### 1. `tauri.conf.json` の修正
Tauriのフロントエンド（JavaScript）から別ウィンドウの作成や操作を行えるよう、パーミッションを追加します。
- `tauri.allowlist.window` に `"create": true`, `"close": true`, `"setFocus": true` を追加します。

### 2. `src/dist/js/ui/shortcuts.js` の修正
メイン画面でのショートカット検知処理に、`F1` キーのフックを追加します。
- `F1` キーが押下された場合：
  - 既にヘルプウィンドウが存在する場合は、そのウィンドウにフォーカスを当てる（最前面に出す）。
  - 存在しない場合は、Tauriの `WebviewWindow` APIを利用して、`help.html` を読み込む別ウィンドウ（横幅・高さを適度に設定）を新規作成する。

### 3. `src/dist/i18n.js` の修正
ヘルプ画面で使用する以下のUIテキスト群（翻訳キー）を追加します。
- ヘルプ画面のタイトル（「ショートカット一覧」）
- 各種カテゴリ名（「ファイル操作」「表示・ズーム」「タブ操作」など）
- 各ショートカット機能の名称

**現在実装されている主なショートカット（一覧化対象）:**
- `Ctrl + S`: 手動保存
- `Ctrl + T`: 新規タブ追加
- `Ctrl + E`: エクスプローラーで開く
- `Ctrl + Tab` / `Ctrl + Shift + Tab`: タブの切り替え
- `Ctrl + [+|-]` または `Ctrl + マウスホイール`: ズームイン/ズームアウト
- `Ctrl + Shift + [+|-]` または `Ctrl + Shift + マウスホイール`: 行間の拡大/縮小

### 4. 新規ファイル: `src/dist/help.html`
ヘルプ画面のマークアップ。
- メインの `index.html` と同様に `style.css` を読み込み、ダークテーマなど全体の世界観を統一。
- カテゴリごとに分けたショートカットのリストをシンプルに表示する構造。

### 5. 新規ファイル: `src/dist/js/help.js`
ヘルプ画面の制御用スクリプト。
- `i18n.js` をインポートし、`help.html` 内の要素に翻訳テキストを適用する。
- `window.addEventListener('keydown')` で `Esc` キーを検知し、Tauri API (`appWindow.close()`) を用いて自身（ヘルプウィンドウ）を閉じる処理を実装する。
