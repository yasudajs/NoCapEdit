# 設定画面のフォント選択における「フォント読み込み中...」表示の実装計画書

## 概要
設定画面でフォント一覧が未読み込みの状態でフォント選択セレクトボックス（`<select id="fontFamilySelectModal">`）をクリックまたはフォーカスした際、フォント走査処理中にセレクトボックス内の表示を「フォント読み込み中...」に切り替え、読み込み中であることを視覚的に明示する機能を追加します。
これにより、操作がフリーズしたように見える現象を防ぎ、快適で安心感のあるUI操作を提供します。

---

## ユーザー確認・合意事項
- 設定画面を開くたびに全フォントを読み込むのではなく、フォント選択セレクトボックスが操作されたときのみオンデマンドで読み込む（アプリ起動・設定画面オープンの最速動作を維持）。
- セレクトボックスの外側に新しいUI要素を配置せず、セレクトボックス内のテキスト切り替え（プレースホルダー的表示）を行うことで、設定ダイアログのレイアウト崩れをゼロにする。
- キーボード操作（Tabキー）時もフォーカスが外れないよう、HTMLの `disabled` 属性ではなくローディング制御クラス・キー制御を用いる。

---

## 変更対象ファイルと詳細

### 1. [MODIFY] `src/dist/i18n.js`
- 多言語化（i18n）テキストの追加:
  - `ui.dialog.settings.font.loading`: `"フォント読み込み中..."`
  - `settings.font.loading`: `"フォント読み込み中..."`

### 2. [MODIFY] `src/dist/js/ui/theme.js`
- `loadSystemFonts()` の改善:
  - 読み込み開始時:
    - `appState.fontsLoading = true`
    - セレクトボックスの選択肢を一時的に `<option value="__loading__" disabled selected>${t('settings.font.loading')}</option>` に変更
    - セレクトボックスにローディング用CSSクラス（`.loading`）を付与し、操作ガード
  - 読み込み完了時:
    - 等幅フォント・その他フォントの optgroup を構築
    - セレクトボックスの選択値を現在の `appState.fontFamily` に復元
    - ローディング用CSSクラスを解除
    - `appState.fontsLoaded = true`, `appState.fontsLoading = false`
    - フォーカス状態の維持
  - 読み込み失敗時（catch）:
    - 元の選択肢（デフォルトまたは現在のフォント）を復元
    - ローディング用CSSクラスを解除
    - エラーステータスを表示

### 3. [MODIFY] `src/dist/js/main.js`
- フォントセレクトのイベントリスナー改善:
  - `mousedown` 時に未読み込み（`!appState.fontsLoaded`）の場合、`e.preventDefault()` して未完了状態でのドロップダウン展開を防ぎ、`loadSystemFonts()` をトリガー
  - `focus` 時に未読み込みの場合も `loadSystemFonts()` をトリガー

### 4. [MODIFY] `src/dist/style.css`
- フォントセレクトのローディング中スタイル（`.font-select.loading`）の定義:
  - `cursor: wait;`
  - `pointer-events: none;`
  - 色合いやフォントスタイルの微調整（サイズやレイアウトは一切変更しない）

## 検証手順

### 手動検証

#### 初期状態確認
- [x] アプリを起動し、設定画面を開く。
- [x] フォント選択に現在の設定フォント（デフォルトまたは保存されたフォント）が表示されており、システムフォントの不要な読み込みが走っていないことを確認。

#### マウス操作時の検証
- [x] フォントセレクトボックスをクリックした瞬間に、セレクト内の表示が「フォント読み込み中...」に切り替わることを確認。
- [x] 読み込み完了後、等幅フォント・その他フォントが正しくグループ表示され、元のフォントが選択状態を維持していることを確認。
- [x] 読み込み完了と同時にドロップダウンリストが自動で開く（2度押し不要）ことを確認。

#### キーボード操作時の検証
- [x] 設定画面を開き、Tabキーでフォントセレクトボックスへフォーカスを移動。
- [x] フォーカスが当たった瞬間に「フォント読み込み中...」と表示され、フォーカスが飛ばずに維持されることを確認。
- [x] EnterまたはSpaceキーで開こうとした場合も、読み込み完了後にドロップダウンが自動展開されることを確認。
- [x] 読み込み完了後、矢印キー（↑↓）でフォント選択が正常に行えることを確認。

#### 設定保存の検証
- [x] フォントを変更してエディタに反映され、設定が保存されることを確認。
