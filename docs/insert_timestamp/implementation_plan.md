# タイムスタンプ挿入ショートカット（F5）追加 実装計画書

## 概要
Windows標準メモ帳と同様に、**`F5` キー** を押すことでエディタのカーソル位置に現在日時（タイムスタンプ）を素早く挿入できるショートカット機能を実装します。
もちろん、ブラウザ標準の Undo（`Ctrl + Z`）/ Redo（`Ctrl + Y`）に完全連動させます。

---

## 仕様詳細

### 1. キーバインド
- **`F5`**: 現在日時を挿入
  - 選択範囲がある場合は、選択範囲を現在日時のテキストで置換
  - 挿入後のカーソルは挿入した日時の直後に移動
  - ブラウザの規定リロード動作を `e.preventDefault()` で抑制
  - 日本語IME変換中は誤動作しないようガード

### 2. 日時フォーマット
- **`YYYY/MM/DD HH:mm`** （例: `2026/08/15 23:05`）
  - 年: 4桁（西暦）
  - 月・日・時・分: 2桁（ゼロ埋め）

## 変更内容の詳細

### 1. エディタ操作モジュール (`src/dist/js/ui/editor.js`)
- `insertTimestamp()` 関数を新設・エクスポート：
  - 現在の `Date` オブジェクトから `YYYY/MM/DD HH:mm` の文字列を生成
  - `applyEditorTextWithUndo` を利用して現在のカーソル位置（または選択範囲）にテキストを挿入・置換
  - 挿入後のカーソル位置を日時の直後にセット

### 2. ショートカット監視 (`src/dist/js/ui/shortcuts.js`)
- `e.key === 'F5'` のキー判定を追加（Ctrl, Alt, Shift が押されていない場合）：
  - `e.preventDefault()` を実行し、`insertTimestamp()` を呼び出し

### 3. 多言語定義 (`src/dist/i18n.js`)
- `help.shortcuts.insertTimestamp`: `"現在日時の挿入"` を追加

### 4. ヘルプ画面 (`src/dist/help.html`)
- 「テキスト編集」カテゴリに `F5`（現在日時の挿入）を追加
